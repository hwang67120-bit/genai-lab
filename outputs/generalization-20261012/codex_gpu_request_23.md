# GPU 시험 요청 23 — 손·꼬리 가림 연출(D-128) 첫 확인 (승인 2026-10-15)

D-128로 손·꼬리를 가리는 연출이면 그 부분을 지시문에서 '보이게 그대로' 요구하지 않는다. 이 규칙으로 실제 생성을 한 적이 없어 두 줄로 확인한다. 실행: **Claude**(Codex 부재 중, 사용자 결정 2026-10-15 "크로드에서 작업 하자"). 상태: **승인** — 사용자 "요청 23 승인, 진행해"(2026-10-15).

## 비교 목적

- 꼬리 가림: 요청대로 꼬리를 가리면서 **꼬리를 없애거나 더하지 않는지**, 앉기 자세·의상·특징 유지.
- 손 가림: 뒷짐 자세가 반영되는지(요청 관찰 태그 `hands_hidden`), 손이 가려져도 팔·의상 이상이 없는지.
- 규칙 끄고 켜기 A/B는 하지 않는다(작업 프로세스가 지시문을 같은 코드로 다시 계산해 대조하므로 규칙을 끈 실행은 계약 위반). "규칙 아래에서 정상 동작하는지"만 본다.

## 입력과 실행

기준·성별·부위·특징표·고유 형태 메모는 요청 21·22에서 사용자가 확인한 값 그대로(`codex-preflight-21-rerun1/proposed-inputs.json`).

| 줄 | 기준 | 요청 | 가림 판단(D-128) | 지시문에서 달라지는 것 |
|---|---|---|---|---|
| N1-tail | 원본 N1(꼬리·날개) | sitting on a simple stool so that her tail is hidden behind her | tail·body_parts | 꼬리 메모(heart-shaped tip) 제외, 부위 문장 "보이는 곳은 같게, 가려져도 되지만 없애거나 더하지 말 것" |
| N2-hands | 원본 N2(귀·꼬리) | standing with his hands behind his back, looking at the viewer | hands | N2 메모에 손 관련이 없어 지시문 변화 없음. 요청 관찰 태그만 |

- 공통 `run_free_generation`, 요청 20~22와 같은 모델·설정. selection_seed 42, 생성 seed 42, 제품 자동 재시도만 43.
- 사전 CPU 검사(`codex-preflight-23/run_23.py`, 인자 없이): 요청 문장 검사 통과, 가림 판단이 위 표와 같음, 입력 SHA·설정 잠금. 실행(`--run`) 중 코드·설정 SHA가 바뀌면 중단. 결과 폴더 덮어쓰기 금지.
- 배치 중 genai_lab 코드 수정 금지.

## 기록

- 비교 그림(줄마다): 원본 | 결과(+재시도) | 꼬리/손 부분 확대.
- 사람 기록: 같은 캐릭터, 의상(같음/일부/다름), 요청 반영(예/일부/아니오), 꼬리 상태(가려짐·보임, 없어짐/추가 여부), 심한 이상, 고유 형태 메모 유지(보이는 것만).
- 자동 기록: `request_tags`(N2 hands_hidden 점수), 부위 검사(N1은 확인 불가로 빠짐), 실제 프롬프트.
- 시간: 한 줄 약 35분, 두 줄 약 70분(재시도 시 최대 약 140분). Qwen 상한 6.5GiB.

## 결과별 다음 결정

- 두 줄 정상: D-128 유지. 우연한 가림(자세 때문에 가려지는 경우)도 다룰지는 운영 판정 20건 뒤 결정.
- 꼬리가 없어지거나 늘어남: 꼬리 가림 문장 표현을 다시 설계(예: "가려도 꼬리는 하나")하고 사용자에게 제안.
- 뒷짐 미반영: 요청 문장 위치·표현 문제로 따로 본다.
