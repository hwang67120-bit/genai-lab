## 판정과 해석 범위

- 그림체 변화는 선·명암 단계·채색 방식 중 캐릭터에서 하나 이상 눈에 띄는지를 사용자가 판단한다. 동일성은 얼굴·눈색·머리색·장식·의상 다섯 항목을 사용자가 판단한다.
- 세 줄 중 두 줄 이상에서 그림체 변화와 동일성이 함께 확인되면 후처리 구조 후보로 남기고 그 밖에는 이번 LoRA 검토를 끝낸다는 기준을 유지한다. 본 보고는 개수나 결론을 대신 산정하지 않는다.
- 원래 입력의 정상 생성 판정은 새 변환의 판정이 아니다. 새 사용자 판정을 생성하거나 기존 판정·캐릭터 기억을 변경하지 않았다.
- 이 LoRA·이 고정 조건의 시험 A로 해석을 한정한다. GGUF Q4_K_M 양자화, 메모리 정책, 가속 없음·40단계 CFG4는 제작자 예시와 동일한 조건이라고 할 수 없다. 대조군이 없어 LoRA 효과와 기준 모델의 편집 효과를 분리하지 못한다.
- 이 결과를 그림체 변환 자체의 가능/불가능이나 직접 학습 필요성으로 일반화하지 않는다. trial: style_pass_borrowed로 격리하며 제품 기본값·품질 기준선·운영 집계·D-118에 넣지 않는다. 미공개 학습 자료인 빌린 LoRA의 제품 채택을 증명하는 시험도 아니다.
- 어느 판정이든 시험B/C나 다른LoRA로 이어가지 않는다. 비교표의 여덟 항목에 대한 사용자 판정이 다음 결정의 입력이다.
