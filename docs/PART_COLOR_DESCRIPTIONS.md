# 귀·꼬리 색상 설명: 전체 생성 격리와 부위 보정 연결

## 현재 상태

- 색상 설명은 전체 캐릭터·의상 생성 프롬프트에 추가하지 않는다.
- 승인된 일반 `animal ears`, `tail` 태그를 색상 설명으로 대체하지 않는다.
- 기존 캐릭터 태그 → 화면 범위 → 의상 → 선택 품질 문구의 조립과 토큰 예산을 사용한다.
- 확정된 색상 설명은 완성 후보에서 해당 귀·꼬리가 검출되고 유사도 기준에 미달한 경우에만
  제한 마스크 Inpaint 프롬프트 맨 앞에 추가한다.
- 판단 보류된 색상은 부위 보정 프롬프트에도 넣지 않는다.
- `applied_part_color_tags`와 `generic_part_tags_replaced_by_color_description`은 빈 값으로 기록한다.

## 유지한 기능

- 원본 마스크의 RGB 색상 측정과 진단 기록.
- 귀·꼬리 검출, RGB 참조, 마스크, 참조 순서·강도.
- 부위별 불변 입력과 최종 승인·실행 입력 검증.
- 성별·의상 조건, 모델, 시드, 후보별 시간 제한은 변경하지 않았다.
- 색상 설명 객체는 승인 계약에 포함하며, 부위 보정 입력의 색상 문구도 결과 진단에 기록한다.

## 제한 연결 정책

`reference_analysis.part_color_text.enabled`는 true다.
색상 이름 제안은 전체 생성 조건이 아니라 `part_error_correction`의 동일 부위에만 연결된다.
색상 이름 제안은 CSS RGB 표본과 OpenCV Lab 거리 기반 실험이며, 표본의 색상군 분류·임계값은 프로젝트 정책이다.
그림자·반사광·기본 털색을 의미적으로 분리하거나 위치·줄무늬·그라데이션을 판정하지 못한다.
따라서 색상군이나 포함률이 모호하면 `unresolved`로 유지하고 자동 문구를 만들지 않는다.

완성 후보에서는 원본 부위와 후보 부위의 Lab 팔레트 분포를 별도로 비교한다.
형태·의미용 CLIP 유사도가 기준을 통과해도 색상 거리가 기준을 넘으면 제한 Inpaint를 실행한다.
이 거리는 양쪽 팔레트의 면적 비율을 사용한 대칭 가중 최근접 거리이며,
줄무늬 위치·그라데이션 방향·반사광 의미를 판정하는 지표는 아니다.

Inpaint에는 현재 후보의 `width`와 `height`를 명시하고, 반환 이미지·후보·마스크 크기가
일치할 때만 합성한다. 후보별 기록에는 입력 크기, 마스크 픽셀 수, 원본·후보 색상 증거,
CLIP 유사도, 색상 거리, 보정 트리거, Inpaint 출력 크기와 최종 결정이 남는다.

## 검증 범위

색상 설명이 존재하더라도 전체 생성 프롬프트가 설명 없는 경우와 동일하고, 일반 부위 태그와
의상 조건이 유지되는지 검사한다. 추가로 확정된 색상만 동일 부위의 제한 Inpaint에 전달되고,
판단 보류 색상은 전달되지 않으며 마스크 밖 픽셀이 보존되는지 검사한다.
이 검사는 입력 연결의 회귀 검사이며 실제 이미지 품질을 보장하지 않는다.
화질 비교는 동일 시드·참조 이미지·마스크·모델·추론 설정으로 별도 수행해야 한다.
