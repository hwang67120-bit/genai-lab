# 프로젝트 범위

## 목표

최종 목표는 Windows에 설치하여 서버 없이 실행하는 아이콘 생성 앱입니다. 사용자가 참조 그림과 생성 내용을 한 화면에서 입력하면 같은 그림체의 후보 아이콘 3장을 빠르게 만들고, 마음에 드는 결과를 선택하여 저장합니다. 마음에 드는 결과가 없으면 해당 실행 결과를 정리하고 다시 3장을 생성합니다. 〔역사 기록 — 지금과 다름: 목표 1〕

## 포함

- Stable Diffusion 1.5 비교용 기준 이미지 생성 〔역사 기록 — 지금과 다름: 목표 2〕
- Animagine XL 3.1 실제 작업용 기준 이미지 생성 〔역사 기록 — 지금과 다름: 목표 2〕
- 한 장 참조 그림 특징 전달(IP-Adapter) 〔역사 기록 — 지금과 다름: 목표 2〕
- 3개 요청의 순차 생성과 중단 후 이어서 실행 〔역사 기록 — 지금과 다름: 목표 3〕
- 요청 문장, 시드, 모델, 시간과 GPU 사용량 기록
- 그림체 일관성 사용자 평가
- 한 장 참조 방식이 부족할 때만 그림체 학습용 추가 가중치(LoRA) 검토
- 포즈와 구도가 부족할 때만 구조 안내 기능(ControlNet) 검토 〔역사 기록 — 지금과 다름: 목표 2〕
- 생성 기능이 안정된 뒤 Windows 설치형 화면 제공
- 참조 그림 선택, 생성 내용 입력, 후보 3장 확인과 선택 저장 〔역사 기록 — 지금과 다름: 목표 3〕

## 제외

- Java 전체
- 백엔드, 웹 서버, API, DB와 로그인 〔역사 기록 — 지금과 다름: 목표 5〕
- 개인정보 및 보안 기능
- 텍스트 생성 AI, 음성 및 영상 생성 〔역사 기록 — 지금과 다름: 목표 5〕
- 1차 출시의 배경 생성과 배경 참조 입력 〔역사 기록 — 지금과 다름: 목표 4〕
- 모바일·웹 화면과 브라우저 실행 방식
- 확대, 부분 수정과 후처리 〔역사 기록 — 지금과 다름: 목표 6〕
- 첫 기준 생성 전에 LoRA 또는 ControlNet 구현 〔역사 기록 — 지금과 다름: 목표 2〕

## 개발 원칙

- 짧은 기간 안에 높은 품질을 내기 위해 검증된 오픈소스를 최대한 활용합니다.
- 이미 공개된 모델, 라이브러리와 구현이 있으면 같은 기능을 처음부터 다시 만들지 않습니다.
- AI가 생성한 코드는 공식 문서와 현재 테스트로 확인한 뒤 채택합니다.
- 채택한 구조는 사용자가 한글로 선택 이유와 실행 흐름을 설명할 수 있어야 합니다.
- 이해하지 못한 코드는 완료로 판단하지 않으며 `STRUCTURE.md`, `FLOW.md`, `DECISIONS.md`와 `GLOSSARY.md`를 통해 배운 내용을 남깁니다.
- 일정 단축은 검증 단계 생략이 아니라 불필요한 기능과 중복 구현 제거로 달성합니다.
