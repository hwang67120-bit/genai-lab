# 원본 머리 자동 붙이기 인수인계

원본 비율 참고를 켜면 윤곽 확인 → 머리카락 영역 확인 → 4장 생성 → 자동 머리 붙이기 → 결과 검토 순서로 진행한다. 원본 비율 참고를 끈 생성에는 적용하지 않는다. 종전의 결과 화면 수동 버튼은 숨겼다. 과거 단일 처리 함수는 재현 비교용으로 보존했다.

## 생성 전 확인과 건너뛰기

확인된 외형 태그에 `short_hair`가 없거나, 의상에 요청서의 머리 덮개 태그가 정확히 일치하면 붙이기만 건너뛴다. 후드 상의라는 이유만으로 후드를 썼다고 판단하지 않는다.

원본과 확인한 머리 윤곽으로 H2 후보를 준비한다. 확인 기록은 기존 원본 SHA·정규화 SHA·머리 마스크 SHA 조합으로 재사용한다. 배경 검사는 원본 머리 크롭에서 분할 합집합과 윤곽을 6px 확장한 바깥쪽만 사용하며, 정규화 회색 여백을 제외한다. 픽셀 RGB 중앙값과 흰색 사이의 유클리드 거리가 10을 넘거나 측정할 배경이 없으면 건너뛴다. 배경 측정값은 `auto-head-confirmation.json`에 기록한다.

기존 눈알 규칙이 실패하거나 사용자가 머리 영역을 거부해도 의상 생성은 진행한다. 결과 화면에는 붙이지 않은 이유가 표시된다. 준비 작업 자체를 취소하면 생성하지 않는다.

## 처리와 결과 저장

생성 모델을 닫고 부모 프로세스의 GPU 예약·할당 메모리가 0인지 확인한 뒤 별도 머리 처리 프로세스를 시작한다. 생성 결과 4장을 한 분할 모델로 분석하고 모델을 내린다. 다시 그리기 모델을 한 번 읽어 마지막 4단계와 기존 보호 합성을 적용한다. 입력·seed·프롬프트·단계·강도·메모리 한도는 바꾸지 않는다. 새 다운로드도 없다.

장별 분할·다시 그리기·흰 배경 합성이 실패하면 해당 장만 붙이기 전 결과로 유지한다. 메모리 한도·모델 정리 실패는 후속 GPU 처리를 중단하며 같은 작업 안에서 다른 방식으로 재시도하지 않는다. 상태와 장별 사유, 모델 로드 횟수, 단계별 시간, 시작 GPU 여유 메모리는 `auto-head-result.json`과 작업 폴더 기록에 남긴다.

결과 선택지는 계속 4개다. 기본은 붙인 결과이며, `붙이기 전 보기`로 같은 후보의 원래 결과를 선택할 수 있다. 승인·저장은 현재 보기의 그림에 적용하며, 저장 기록의 `head_view`는 `pasted` 또는 `before`다. 다른 결과 고르기는 현재 보기를 승인하지 않은 것으로 기록하고 다음 장으로 순환한다. 보기 방식은 유지하되 기존 승인은 해제한다.

## 취소와 메모리

계산 오류의 완료된 traceback 프레임을 끊고, 작업 종료 신호 전에 GC와 GPU 캐시 정리를 수행한다. 이렇게 해야 화면 완료 콜백에서 시작하는 다음 작업과 정리가 겹치지 않는다. 생성 백엔드는 모델 로드 직전에도 같은 정리를 수행하고 `memory_before_backend`를 기록한다.

GUI 전체 생성을 취소하면 작업을 안전하게 마치거나 하위 프로세스를 종료한 뒤, 이번 작업이 독점 생성한 `generation/`만 폐기한다. 자동 머리 처리 출력도 그 아래에 있어 함께 폐기된다. 입력과 이미 저장한 그림, 사용자 머리 확인 캐시는 유지한다. 취소 정리가 실패하면 다음 생성은 막고 재시작 안내를 표시한다.

## Claude GPU 확인

GPU는 구현 중 실행하지 않았다. CPU 검사 통과는 GPU 픽셀 재현이나 실제 VRAM 반환의 증거가 아니다.

기존 gpu-03의 세 캐릭터 × seed 두 개를 각각 일괄 처리한다. 새 생성 없이 기존 후보를 사용하며, head_1024·raw_redraw·흰 배경 제품 SHA가 기존 결과와 일치해야 한다. 첫 불일치에서 멈추고 기록을 보존한다. 출력 폴더가 이미 있으면 새 이름을 사용한다.

```powershell
& 'D:\genai-cache\venv\Scripts\python.exe' -B '.\scripts\verify_auto_head_batch.py' --gpu --output 'outputs/auto-head-paste-20261010/gpu-01'
```

프로젝트 폴더에서 실행한다. 같은 실행기에서 `--gpu`를 빼면 저장된 분할 자료로 CPU 붙이기 입력만 대조한다. GPU 재현 후 GUI에서 4장 전체 자동 처리 시간을 측정하고, 생성 → 취소 → 재생성을 같은 앱에서 확인한다. 검증 범위는 여전히 세 캐릭터이며 긴 머리·비흰색 배경·모자 적용의 일반화는 완료되지 않았다.
