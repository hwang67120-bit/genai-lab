# 용어집

| 한글 설명 | 공식 용어 | 이 프로젝트에서 하는 일 |
|---|---|---|
| 이미지 생성 기본 모델 | Stable Diffusion | 생성 문장으로 새 이미지를 만듭니다. |
| 참조 그림 특징 전달 장치 | IP-Adapter | 참조 그림의 시각 특징을 생성 과정에 전달합니다. |
| 그림체 학습용 추가 가중치 | LoRA | 여러 참조 그림의 공통 그림체를 작은 파일로 학습합니다. |
| 포즈·윤곽·깊이 구조 안내 | ControlNet | 생성 이미지의 구도와 형태를 더 강하게 제어합니다. |
| 생성 요청 문장 | Prompt | 이미지에 포함할 내용과 분위기를 설명합니다. |
| 제외 요청 문장 | Negative prompt | 피하고 싶은 형태와 품질 문제를 설명합니다. |
| 난수 시작 번호 | Seed | 같은 생성 조건을 다시 만들기 위한 숫자입니다. |
| 반정밀도 숫자 | float16 | GPU 메모리를 줄이기 위한 숫자 표현 방식입니다. |
| 그래픽카드 메모리 | VRAM | 모델과 생성 중간 값을 저장하는 GPU 전용 메모리입니다. |
| 실행 기록 | Manifest/result.json | 어떤 입력과 설정으로 결과를 만들었는지 저장합니다. |
| Windows 인증서 연결 | truststore | 인증서 검사를 끄지 않고 Windows의 신뢰 목록을 Python에서 사용합니다. |
- **애니 그림 확대 복원(Real-ESRGAN anime)**: 작은 애니 그림을 키우며 선과 색 경계를 복원하는 모델입니다. 없던 세부를 잘못 추측할 수 있어 보정본을 사용자가 확인합니다.
- **얼굴·손 위치 탐지(YOLO)**: 생성 이미지에서 얼굴과 손이 있는 네모 영역을 찾는 모델입니다. 정상 여부를 확정하는 기능은 아닙니다.
- **부분 재생성(Inpaint)**: 지정한 마스크 안쪽만 다시 그리는 방식입니다. 이 프로젝트는 마스크 밖 변경을 허용하지 않습니다.
- **마스크**: 다시 그릴 수 있도록 허용한 흑백 영역입니다. 흰 부분만 보정하고 검은 부분은 원본을 유지합니다.
