# 합성 없는 참조 분석 경로

2026-09-08 추가: 귀·꼬리 원본 자동 검출/미리보기 로더를 연결했다. 생성 위치 판단은 아직 미구현이며
기본 경로는 검출 결과를 생성 참조로 전달하지 않는다. 현재 동작은 [선택 및 검출 문서](CHARACTER_SELECTION_AND_PART_DETECTION.md)를 참고한다.

## 이번 연결

기본 시각 참조 생성은 reference_regions.analyze_reference_regions를 호출한다.
기존 execute_character_body_comparison 전체 호출을 사용하지 않는다.
공용 분석 실행기는 --reference-output-dir 모드에서 영역 파일만 반환하고 종료한다.
중립색 이미지, 제거 성공률, 제거 잔여 마스크, DensePose 미리보기를 만들지 않는다.
DensePose와 SCHP 모델 자체는 AutoMasker의 영역 계산 의존성으로 여전히 사용한다.
CatVTON 합성 모델을 실행한다는 의미가 아니며, 모델 로딩 비용이 없어졌다는 뜻도 아니다.

원본을 분석 크기로 자르지 않고 비율 유지 여백을 사용한다.
출력 마스크는 기록된 내용 영역에서 여백을 제거한 후 원본 좌표로 복원한다.
의상 참조 영향 영역은 자동 의상 영역과 전경의 교집합에서 얼굴·헤어를 제외한다.
이 경로에는 합성용 팽창·중립화·제거 검증이 없다. 기존 마스크와 달라질 수 있으므로 입력 승인을 유지한다.
원본 위치의 영향 마스크는 생성 포즈/실루엣을 고정하는 수단이 아니다.

## 색 분포

기본 분석기는 SCHP 헤어 영역의 색 분포만 측정한다.
Lab 변환은 이미 의존하는 OpenCV를 사용하여 새 모델이나 패키지를 추가하지 않았다.
로컬 난수 생성기를 사용하는 유한 반복 군집화이며 최대 학습 표본 20,000,
거리 계산 청크 20,000, 군집 수 최대 8, 갱신 최대 20회로 제한한다.
작은 포인트 색은 표본에서 누락될 수 있다.
흰색/검정 픽셀을 반사광/그림자로 일괄 제거하지 않는다.
군집 수는 디자인 색 개수가 아니며 명암·그라데이션·줄무늬·오드아이를 확정하지 않는다.

입력 승인 화면에 색상칩과 면적을 표시한다.
후보 폴더의 part_colors/에 JSON, 색 군집 위치 NPY(-1은 영역 밖),
확인용 PNG를 저장한다. PNG를 생성 조건으로 보내지 않는다.
현재 눈색 WD 분석 및 다중 색 선택은 그대로 유지한다.
좌우 홍채 분할과 눈색의 공간적 패턴 분석은 아직 구현되지 않았다.

## 귀·꼬리 등의 추가 참조

reference_analysis.part_analyzer는 Python 구현체 연결 지점이며 기본 구현체는 없다.
AdditionalPartAnalyzer.analyze는 소유권이 독립적인 DetectedPart 목록을 반환하고
close로 모델 자원을 해제해야 한다. UI에서 사용자가 마스크를 작성하도록 요구하지 않는다.
분석기는 취소 콜백/마감 시각을 확인해야 하며, 부모는 반환 후에도 마감 시각을 확인한다.
블로킹 외부 모델 호출의 강제 제한은 구현체의 프로세스 감독 책임이다.

부위 이름은 ears/tail/wings/horns 및 숫자 접미사만 허용한다.
원본 추출 마스크와 생성 영향 마스크를 구분한다.
빈 마스크, 잘못된 좌표, 강도 오류, 참조끼리의 중첩은 승인 전에 거절한다.
앞머리·귀처럼 실제 겹침이 있는 경우 분석기가 가려짐을 해결해야 한다.
지원되지 않는 부위를 조용히 전신 크롭으로 대체하거나 '없음'으로 확정하지 않는다.
검증된 추가 참조는 입력 승인 화면, 디버그 저장, IP-Adapter 이미지/마스크/강도,
A/B 비교 경로까지 전달된다. 의상 OFF 실험에서도 추가 부위 강도는 유지된다.

## 유지한 기능과 한계

- 초기 RGB 입력 차단, 수동 성별 우선, 프롬프트 예산/승인 확인 유지.
- 기존 얼굴·헤어와 의상 참조 강도 기본값 유지.
- 선화 실험은 계속 비활성. 검증된 분석기 없이 자동 활성화하지 않음.
- CPU offload 등 기존 메모리 설정 유지. 8GB 실행 가능 여부를 새로 보장하지 않음.
- 의상 디테일 전용 추출은 미구현. 해당 모드를 지정하면 분석 시작 전에 중단.
- 의상 태그에서 성별을 제외해도 이미지의 체형 영향이 제거되는 것은 아님.
- 전신 유사도는 기존대로 참고값이며 생성 조건이나 합격선으로 쓰지 않음.

후보 생성 취소/제한 시간은 다음 추론 단계 콜백에서 확인한다.
완료된 이전 후보는 기존 배치 처리와 동일하게 보존한다.
준비 단계나 단일 GPU 호출을 즉시 중단하는 하드 실시간 제한은 아니다.
영역 분석 외부 프로세스는 소유한 프로세스를 종료하는 별도 취소·시간 제한을 갖는다.

후보 비교의 선택형 상세 기록에 성별 조건·눈·헤어·귀·꼬리·의상·인체 확인을 추가했다.
기록은 자동 합격을 만들지 않으며 최종 저장 승인은 별도 단계다.

## 검증 범위

단위 테스트는 분리된 호출 경로, 클래스 ID 보존, 좌표 복원,
색 분포와 위치 기록, 입력 검증, 참조 임베딩 전달, 승인 순서와 취소를 확인한다.
실제 SCHP/WD/GPU 모델을 새로 실행한 품질 검증과는 구분한다.
통합 적용 후 동일 시드로 원본/참조 입력을 확인하고 실제 이미지를 비교해야 한다.
