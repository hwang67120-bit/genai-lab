# GPU 시험 요청 24 — N2-2 눈길: 장면 조명에서 고유 색 유지 문장(D-129) 한 요소 비교 (승인 2026-10-15)

사용자 판정: 요청 20 N2-2(최종 2차)·요청 21 N2-2 모두 원본의 밝은 분홍·붉은 기가 회색으로 바뀜. 같은 N2를 흰 배경으로 생성한 요청 23 N2-hands는 분홍이 남음(사용자 정상). D-129로 배경·장면 요청일 때 "장면 조명이 고유 색을 바꾸지 않게" 문장을 넣는다. 이 시험은 **그 한 요소만 바꾼** 최소 비교다. 상태: **승인** — 사용자 "권고대로 진행하고 푸쉬 해줘"(2026-10-15, 해결안 = 공통 문장 구현 + 요청 24). 실행: **Codex**. 실행 코드는 D-129 커밋 이후 HEAD.

## 비교 목적

- 같은 기준·특징표·메모·요청(walking in a snowy street)·selection_seed 42·생성 seed 42에서 지시문에 아래 문장 하나만 더했을 때 분홍빛이 남는지:
  `Keep the character's own hair, eye, skin and outfit colors exactly as in image 1; the scene lighting must not change or wash out these colors.`
- 요청 21 N2-2(`free-r21-rerun1/N2-2/qwen/model_inputs/prompt.txt`)와 지시문 차이는 이 문장 하나뿐이어야 한다(Claude CPU 대조 확인, 실행 전 Codex가 다시 대조).
- 한 번의 생성이라 우연일 수 있다. 분홍이 남으면 "효과 가능성 있음", 또 회색이면 "이 문장만으로는 부족"으로만 기록한다.

## 입력과 실행

| 줄 | 기준 | 요청 | 비교 대상 |
|---|---|---|---|
| N2-2 | 원본 N2(요청 20~23과 같은 SHA·특징표·성별·부위·메모 X-shaped hair clip) | walking in a snowy street | 요청 21 N2-2 |

- 입력: `codex-preflight-21-rerun1/proposed-inputs.json`의 N2 행. 재시도는 제품 규칙대로(확신 있는 위반만 seed 43).
- 사전 대조·잠금은 요청 22 방식(`codex-preflight-22/run_one.py`)을 따른다: 요청 21 지시문에 위 문장만 더한 것과 실제 지시문이 같은지, 입력 SHA·참조 크롭 [304,33,463,278]·설정 같음, 코드 SHA 잠금, 결과 폴더 덮어쓰기 금지. 단일 실행은 UNC 경로로.
- 배치 중 Claude는 genai_lab 코드를 수정·커밋하지 않는다.

## 기록

- 비교 그림 한 장: 원본 | 요청 21 N2-2 | 요청 24 N2-2(+ 머리 확대).
- 사람 기록: 머리 분홍빛(유지/약함/회색), 같은 캐릭터, 의상(같음/일부/다름), 요청 반영, 심한 이상(팔다리 개수 포함), X 장식 메모 유지.
- 자동 기록: `hair_color.reduced_colors`(분홍 비중, 원본 17.8% / 요청 21 6.7%), 실제 프롬프트 차이.
- 시간 약 35분(재시도 시 약 70분), Qwen 상한 6.5GiB.
