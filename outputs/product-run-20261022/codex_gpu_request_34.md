# GPU 시험 요청 34 — 사용자 화면 흐름 그대로 무작위 5줄 (승인 2026-10-22)

## 요약

- **목적:** 사용자 화면(D-151) + 장면 조합 2판(D-155)이 실제 GPU에서 처음부터 끝까지 도는지 확인하고, 품질(색감·빛·비율·표정·해상도)을 사용자가 판정할 결과를 만든다.
  - 사용자 화면 = 참조 이미지 → '이미지 생성' → 자동 흐름 → 저장
  - 개선 시험이 아니라 **제품 그대로의 실사용 측정**이다.
- **상태:** 승인.
  - 사용자 "자동으로 GUI하고 동일한 방식으로 GPU 테스트로 무작위로 의상 없이 2~3장, 의상 있음 1~2장 … 테스트이기 때문에 코덱스한테 인계하자"(2026-10-22).
- **실행:** Codex. 코드: 이 문서를 커밋한 HEAD(Claude 커밋). 실행 중에는 코드 수정·커밋 없음.

## 실행

1. 환경 점검(필수 실패 0이어야 진행):

   ```
   D:\genai-cache\venv\Scripts\python.exe scripts\check_runtime_env.py
   ```

2. 실행(사용자 화면을 화면 없이 띄우고 줄마다 '이미지 생성' → 끝나면 '저장'):

   ```
   D:\genai-cache\venv\Scripts\python.exe scripts\product_flow_run.py outputs\product-run-20261022\cases.json outputs\product-run-20261022
   ```

   - `GENAI_STUDIO_DEVELOPER`를 켜지 않는다(켜져 있으면 실행기가 멈춤).
   - 상태 파일 `outputs/product-run-20261022/batch-status.json`.

**예상 시간:**
- 의상 없는 줄: 약 35분, 재시도가 생기면 약 70분
- 의상 있는 줄: 옷 바꾸기 30~77분 + 자세·장면 35~70분
- 합계 약 4~8시간

**설정:** 제품 그대로다(40단계, CFG 4.0, 재시도 R3, 머리색 자동 보정, 메모리 상한 6.5GiB). 가속·시험 선택지 없음.

## 중단·기록 규칙

- `memory_stopped` 또는 PyTorch reserved > 6.5GiB → 그 줄은 실패로 기록하고 다음 줄로 간다. **상한을 완화하지 않는다.**
- 입력이 안전 태그로 거부되면(`unsafe_input`) 그 줄을 실패로 기록하고 다음 줄로 간다. 우회하지 않는다.
- 줄 하나가 240분을 넘으면 실행기가 실패로 넘긴다.
