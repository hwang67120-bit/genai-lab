## 대상

## 정답 라벨 (Claude 육안, 측정 전 잠금)
몸 방향: 정면(3/4 포함) / 옆 / 뒤. 얼굴 방향: 정면(3/4 포함) / 옆(프로필) / 아래·위로 숙임(얼굴 거의 안 보임) / 뒤.
"정면 아님" = 몸 방향이 옆·뒤이거나 얼굴 방향이 옆·숙임·뒤.

## 신호 (설치된 도구만)
- S0 (현재): DWPose 코·두 눈 신뢰도 >= 0.30 이면 정면.
- S1 얼굴 윤곽 비대칭: DWPose 얼굴 68점(전체 133점 중 24~91). r = (코끝 x − 턱선 0번 x) / (턱선 16번 x − 턱선 0번 x). 0.30 <= r <= 0.70 이면 정면, 아니면 정면 아님. 얼굴 점 평균 신뢰도 < 0.30 이면 "얼굴 안 보임" → 정면 아님.
- S2 어깨 폭: 좌우 어깨 거리 / 몸통 길이 T. < 0.45 이면 몸 옆모습.
- S3 태거: WD 태거를 원본 자세 이미지에 적용. profile·from_side·from_behind 중 하나 >= 0.35 또는 looking_at_viewer < 0.35 이면 정면 아님(③ 안내 조건과 같은 계열).
- S4 조합: S1 또는 S2 또는 S3 이 "정면 아님"이면 정면 아님.

## 판정 (18장, 골격 검출 실패로 신호를 못 재는 이미지는 "측정 불가"로 따로 셈)
