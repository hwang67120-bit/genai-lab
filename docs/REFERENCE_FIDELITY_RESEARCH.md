# 참조 동일성 연구 근거

상태: 검토 초안  
목적: 캐릭터 참조 한 장과 의상 참조 한 장으로 새로운 이미지를 만들 때, 무엇을 동일성으로 정의하고 어떤 연구를 제한적으로 적용할지 정리한다.

## 문제 정의

입력은 캐릭터 참조 `C`와 의상 참조 `G`, 출력은 새 이미지 `O`다.

목표는 전체 픽셀을 복사하는 것이 아니라 다음 조건을 동시에 만족하는 것이다.

- `O`의 캐릭터 정체성은 `C`를 따른다.
- `O`의 의상 디자인은 `G`를 따른다.
- `C`의 기존 의상은 새 의상으로 누설되지 않는다.
- `G`에 사람이 있을 경우 그 사람의 얼굴, 체형, 헤어와 포즈는 `O`로 누설되지 않는다.
- 자세·배경·표정은 사용자가 요청한 범위에서 바뀔 수 있다.

이를 `참조 동일성(reference fidelity)`이라고 부른다. 동일 입력을 여러 번 생성했을 때 결과끼리 비슷한 정도인 `반복 일관성(repeat consistency)`과 분리한다.

## 연구별 적용 범위

### IP-Adapter

이미지 조건과 텍스트 조건을 분리된 cross-attention으로 전달한다. 현재 프로젝트처럼 캐릭터 이미지와 텍스트 조건을 함께 사용하는 구조의 기본 근거가 된다.

- 적용 가능: 이미지 조건과 텍스트 조건 분리, 참조 강도 조절
- 해결하지 못함: 캐릭터와 의상 두 이미지의 역할을 자동 분리하거나 동일성을 보장하지 않음
- 논문: https://arxiv.org/abs/2308.06721

### BLIP-Diffusion과 AnyDoor

BLIP-Diffusion은 일반 주체 표현을 이미지와 텍스트로 조건화한다. AnyDoor는 identity feature와 detail feature를 분리해 대상의 세부 정보를 보존하면서 위치·조명·자세 변화를 허용한다.

- 적용 가능: 얼굴만이 아닌 일반 캐릭터·수인·사물의 주체 특징과 세부 특징을 분리하는 설계
- 제한: 현재 Animagine/FLUX 파이프라인에 그대로 결합할 수 있는 드롭인 구성은 아님
- 논문: https://arxiv.org/abs/2305.14720
- 논문: https://arxiv.org/abs/2307.09481

### InstantID, PhotoMaker, PuLID

단일 또는 복수 얼굴 이미지에서 ID 표현을 추출해 얼굴 동일성을 높이는 연구다.

- 적용 가능: 강한 의미 조건과 약한 공간 조건 분리, ID 삽입 전후의 편집 가능성 보존, 복수 Anchor 표현
- 직접 적용 금지: 주 평가 대상이 실사 얼굴이므로 애니 캐릭터, 수인 얼굴, 전신 체형, 동물귀·꼬리 동일성을 보장하지 않음
- 논문: https://arxiv.org/abs/2401.07519
- 논문: https://arxiv.org/abs/2312.04461
- 논문: https://arxiv.org/abs/2404.16022

### DreamBooth

소수의 동일 주체 이미지로 고유 식별자를 학습해 다른 자세와 장면에서 주체를 재현한다.

- 적용 가능: 사용자가 승인한 다중 시점 이미지가 축적된 뒤 캐릭터 전용 학습
- 현재 단계에서 제외: 참조 한 장마다 즉시 학습하면 과적합과 배경·의상 결합 위험이 큼
- 논문: https://arxiv.org/abs/2208.12242

### IDM-VTON과 OOTDiffusion

사람 이미지와 의상 이미지를 따로 받아 의상 의미와 저수준 특징을 별도 경로로 주입한다. 단순 프롬프트보다 의상 전용 특징 경로가 필요하다는 근거가 된다.

- 적용 가능: 의상 고수준 의미와 저수준 패턴·소재를 분리하고, 의상 조건을 캐릭터 조건과 다른 경로로 전달
- 직접 적용 제한: VITON-HD·DressCode 계열의 사람 사진과 의복 데이터 분포를 전제로 하므로 애니·수인·성별 교차·비인간 체형은 별도 검증 필요
- 논문: https://arxiv.org/abs/2403.05139
- 논문: https://arxiv.org/abs/2403.01779

### StoryDiffusion

여러 결과 사이의 주체 일관성을 높이는 Consistent Self-Attention을 제안한다.

- 적용 시점: 동일성이 승인된 Anchor가 만들어진 뒤 반복 이미지 생성 단계
- 선행 문제를 해결하지 못함: 첫 Anchor가 잘못된 캐릭터라면 잘못된 특징이 반복될 수 있음
- 논문: https://arxiv.org/abs/2405.01434

## 평가 근거

DreamBooth 연구는 주체 충실도 평가에서 DINO가 CLIP-I보다 사람 평가와 더 잘 맞는 사례를 보고했다. CLIP-I는 넓은 의미를 반영하지만 텍스트 주석에 없는 미세 특징을 놓칠 수 있다.

따라서 본 프로젝트는 다음을 단독 정답으로 사용하지 않는다.

- 전체 이미지 CLIP 점수
- 전체 픽셀 SSIM 또는 LPIPS
- 전경 마스크 IoU
- 얼굴 인식 점수 하나

평가는 캐릭터와 의상 마스크를 분리한 뒤 `Masked DINO + CLIP-I + 구조·색상·토폴로지 + 사용자 판정`으로 구성한다. DINO와 CLIP 점수는 확률이나 정확도가 아니며, 고정 검증 세트의 사람 라벨로 임계값을 보정하기 전까지 진단값이다.

- DreamBooth 본문 및 보충 자료: https://arxiv.org/abs/2208.12242
- DreamBooth 보충 자료: https://openaccess.thecvf.com/content/CVPR2023/supplemental/Ruiz_DreamBooth_Fine_Tuning_CVPR_2023_supplemental.pdf

## 채택 결론

1. 동일성 Anchor를 먼저 만든다.
2. 캐릭터와 의상 조건은 독립 경로와 독립 평가 항목을 사용한다.
3. 얼굴 전용 ID 모델은 애니·수인에 대한 별도 검증 없이는 공통 계약으로 채택하지 않는다.
4. 반복 일관성 기법은 승인 Anchor 이후에만 시험한다.
5. 단일 평균 점수로 합격시키지 않는다.
6. `unresolved`는 실패나 부재로 바꾸지 않는다.
7. 학습은 승인된 다중 시점 자료가 모인 뒤 별도 실험으로 진행한다.
