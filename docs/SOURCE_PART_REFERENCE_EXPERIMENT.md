# 귀·꼬리 원본 RGB 연결 실험

현재 제품 계약과의 관계는 [활성 제품 계약과 전체 흐름](FLOW.md)을 따른다.
현재는 experimental_overlap_v2 제안과 사용자 입력 승인을 구분하며,
승인 뒤 RGB·영역·실험 정책이 변경되면 생성 전에 재승인을 요구한다.

2026-09-09 사용자 요청에 따라 part_detection.conditioning_mode를
source_regions_experiment로 설정했다. preview_only와 구분되는 명시적 실험이다.

## 실제 연결

1. DINO/SAM2 개별 후보의 의상 중복률과 헤어 중복률을 분리해 검사한다.
   - 의상 중복률 90% 이상은 의상 지배 후보로 제외한다.
   - 귀 후보는 후보의 50% 이상이 헤어이면서 전체 헤어의 50% 이상을 덮을 때
     머리 전체 후보로 제외한다. 작은 귀가 헤어로 분류된 것만으로 제외하지 않는다.
   - 나머지 부분 겹침 후보는 마스크를 깎지 않고 원본 RGB와 함께 검토 대상으로 유지한다.
     승인 UI에 겹침 경고가 표시된다.
   - 이는 프로젝트의 실험적 휴리스틱이며 의미 분류나 품질 보장이 아니다.
     실제 귀가 헤어 대부분을 차지하거나 의상 마스크 자체가 크게 틀리면 여전히 오판할 수 있다.
     소매의 의상 중복률이 90% 미만인 경우 통과할 수도 있으므로 크롭 승인을 유지한다.
   예전 max_source_overlap=0.10 설정은 폐기하고 garment_dominance /
   broad_hair_coverage 설정으로 분리했다.
2. 남은 마스크로 원본 RGB를 흰 배경에 추출한다. 대표색 3개로 다시 칠하지 않는다.
3. 원본 부위 마스크를 생성 영향 영역의 기준으로 사용한다. 자동 자세 정렬이 아니다.
   - 귀는 원본 검출·RGB·색상 측정 마스크를 그대로 보존한다.
   - 생성용 귀 지역 마스크만 Diffusers의 실제 attention mask 축소 결과를 측정해
     설정된 최소 셀을 만족할 때까지 제한적으로 팽창한다.
   - 꼬리는 이번 단일 변수 실험에서 보강하지 않는다.
4. 귀·꼬리 영향 영역에 해당하는 픽셀을 얼굴·의상 영향 영역에서 제외한다.
   원본 얼굴 RGB와 원본 이미지 자체는 수정하지 않는다.
5. 입력 승인 후 기존 IP-Adapter에 얼굴·귀·꼬리·의상 참조와 각 마스크를 전달한다.
   양쪽 부위가 남았을 때 참조 순서와 강도는
   identity 0.7 / ears 0.35 / tail 0.35 / garment 0.45다.

부위가 모두 제외되면 참조 없이 생성하지 않고 중단한다. 일부만 검출되면 실제
전달된 부위 이름과 개수를 표시한다. 귀와 꼬리가 서로 겹치거나 분리 후 얼굴/의상
영역이 비면 중단한다. 소매 제외와 영역 배정은 의미 인식의 정확도를 보장하지 않는다.

## 확인할 항목

- 검토 화면: 귀·꼬리 RGB 전달 / 원본 위치 실험이라는 안내, 실제 크롭과 영향 마스크.
- 후보 JSON: regional_reference_names에 실제 귀·꼬리가 있는지.
- 임시 후보 폴더: ears 및 tail 하위의 참조 PNG와 target_region.png.
- 검출 진단 parts.json: filter_policy, 후보별 의상 중복률/헤어 중복률/전체 헤어 포함률,
  제외 사유 및 requires_review 기록. candidate_index로 SAM2 원래 후보 번호를 유지한다.
- source_garment_mask.png / source_hair_mask.png 및 *_candidate_*_mask.png:
  제외된 후보와 저품질 후보도 저장한다. PNG와 JSON으로 모델 재실행 없이 필터를 재현한다.
- part_region_experiment: 영향 영역 분리 수치와 pose_locked=false.

이번 설정은 귀·꼬리 참조 연결 효과를 시험한다. 원본과 다른 자세에서는 영역이
어긋날 수 있다. 같은 시드/성별/의상/해상도를 사용해 이전 기록과 비교하되,
기존 마스크 오검출 필터도 달라졌으므로 순수한 단일 변수 실험이라고 해석하면 안 된다.
성별·의상 체형 분리, 의상 디테일 패치, 초기 RGB 재도입, 시드 정책은 변경하지 않았다.
실제 GPU 이미지 생성은 이 변경 검증에 포함하지 않았다.

## 귀 생성 영역 보강 실험

2026-09-10부터 generation_region_strengthening 설정을 귀에만 적용한다.
고정 픽셀 수를 바로 사용하는 대신 출력 크기에 비례한 최대 반경 안에서 1픽셀씩
후보를 만들고, 설치된 Diffusers IPAdapterMaskProcessor.downsample 결과로
252-query 단계 2셀과 66-query 단계 1셀이 0.10보다 강하게 남는 최소 반경을 선택한다.
면적이 원본의 2배를 넘거나 최대 반경 안에서 기준을 만족하지 못하면 생성 전에 중단한다.

선택된 반경, 원본/생성 픽셀 수, 면적 증가율, 단계별 셀 수는
part_region_experiment.generation_region_strengthening에 기록하며 승인 화면에도 표시한다.
확장된 마스크는 독립 조건과 승인 지문에 포함되므로 승인 후 변경할 수 없다.
색상 문구, 귀·꼬리 참조 강도, 원본 RGB 크롭, 원본 검출 마스크는 변경하지 않는다.
이 변경은 작은 지역 조건의 수치적 소실을 줄이는 실험이며 귀 색상 재현을 보장하지 않는다.

근거: [Diffusers IP-Adapter 영역별 마스킹](https://huggingface.co/docs/diffusers/v0.38.0/en/using-diffusers/ip_adapter#masking).
이 API는 이미지 참조를 출력 영역에 배정하며, 정확한 자세나 배색을 보장하지 않는다.


## 이번 수정 검증 범위

- 필터·검출기·입력 승인·참조 전달·계약 관련 회귀 테스트 94개 통과.
- 로그의 중복률을 본뜬 합성 마스크로 부분 겹침 보존, 의상 지배 후보 제외,
  작은 귀/머리 전체 후보 구분을 확인했다.
- DINO/SAM2 출력은 테스트 대역을 사용했다. 실제 생성 모델 실행이나 품질 검증이 아니다.
- 이전 실패 실행은 후보별 원시 마스크를 저장하지 않아 픽셀 단위 재생이 불가능하다.
  새 저장 경로는 이후 실패에서 같은 문제를 줄이기 위한 것이다.

개념 근거: [Transformers SAM2 공식 문서](https://huggingface.co/docs/transformers/model_doc/sam2)는
박스/점 입력으로 객체 마스크를 생성하는 API를 설명한다.
여기서 사용하는 90%/50% 판정은 공식 모델의 의미 분류 규칙이 아니라
프로젝트에서 검토용으로 도입한 별도 휴리스틱이다.
