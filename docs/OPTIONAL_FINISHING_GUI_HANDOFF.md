# 고화질 마무리 선택 기능과 재현 확인

고화질 마무리를 결과 화면의 선택 기능으로 연결했다. 생성 직후 자동 마무리는 기본 꺼짐이다. GPU는 실행하지 않았으며, 같은 seed의 기존 시험과 재현 비교 및 실제 사용자 조작 확인이 남아 있다.

## 사용 흐름

결과 선택 → 고화질 마무리 → 한 장 처리 → 마무리 전·후와 얼굴 확대 비교 → 사용할 이미지 선택 → 기존 결과 확인 → 저장.

비교 창의 기본 선택은 마무리 전 원본이다. 창을 닫거나 원본 유지를 누르면 현재 이미지와 기존 승인을 유지한다. 마무리본을 선택하면 승인을 해제하므로 눈색·장식·의상 등을 다시 확인해야 저장할 수 있다.

| 상황 | 동작 |
| --- | --- |
| 일반 생성 결과 | 선택한 한 장만 마무리 |
| 실패 또는 취소 | 원본 유지, 미완료 결과는 채택하지 않음 |
| 마무리본 채택 후 꼬리 고치기 | 1104×1848 마무리본이 새 기준 이미지 |
| 꼬리 편집본 | 마무리 버튼 비활성화, 이유 표시 |
| 원본 비율 참고로 생성한 결과 | 이번 범위 밖이므로 마무리 비활성화 |
| 이미 마무리한 결과 | 중복 실행 비활성화 |

다른 후보를 선택하면 기존 후보의 마무리 선택과 승인은 해제된다. 파생 파일은 실행 폴더에 남는다. 후보별 선택 복원 기능은 이번에 추가하지 않았다. 얼굴 검출이 안 된 경우에는 기존 마무리 계약대로 얼굴 보정을 건너뛰고, 비교 창에 얼굴 확대를 표시할 수 없다고 안내한다.

## 고정 조건과 파일 보존

1.5배, 1104×1848, 강도 0.35, 28단계, CFG 5.5, 원본 seed와 저장된 프롬프트·토큰을 그대로 사용한다. 얼굴 참조는 항상 0.9로 켜며 기존 블록 오프로드를 사용한다. 6.5 GiB 초과 시 중단하는 기존 계약은 유지한다. 품질 태그를 추가하거나 기본값을 바꾸지 않는다.

선택한 raw, 생성 기록, 얼굴 참조를 `generation/optional-finishing/<실행 ID>/` 아래 새 폴더로 복사한다. 원본 묶음의 생성·배경·마무리 기록은 덮어쓰지 않는다. 설정·기본 모델·얼굴 참조와 원본 SHA가 다르면 모델 실행 전에 중단한다.

| 기록 | 내용 |
| --- | --- |
| optional-finishing.json | 진행/실패/취소/검토 대기, 기준 SHA, 결과 경로, 전체 시간 |
| seed-<번호>/finishing.json | 얼굴 참조, 단계별 SHA·시간·메모리·오프로드 |
| seed-<번호>/background.json | 마무리 → 흰 배경 결과의 SHA 연결 |
| selection.json | 원본/마무리본 중 사용자 선택 |
| gui-status.json | GUI 실행 실패 또는 취소 사유 |
| user-review.json, 저장 파일.review.json | 마무리 적용 여부, 원본·선택 이미지 SHA, 마무리·배경·꼬리 기록 |

`awaiting_user_review`는 연산 완료 후 비교를 기다리는 상태이며 사용자 승인을 의미하지 않는다. 흰 배경 정리 실패도 선택 기능 전체의 실패로 처리한다. 취소 시 남은 중간 파일은 지우지 않지만 사용자에게 완료 결과로 제공하지 않는다.

## 읽기 시작할 함수

- `genai_lab/studio_controller.py`: `finish_selected_image` → `finishing_ready` 또는 `finishing_failed`.
- `genai_lab/studio_optional_finishing.py`: `finish_selected`가 한 장 복사·마무리·배경 정리를 연결한다. `finishing_info`가 채택·저장 때 파일 연결과 SHA를 다시 검사한다.
- `genai_lab/studio_finishing_gui.py`: 전후 비교와 원본 기본 선택.
- `genai_lab/studio_generation.py`: `StudioResults.adopt_finishing`, `verify_basis`, `export`가 승인과 꼬리 편집 기준을 관리한다.

기존 마무리 백엔드·오프로드·좌표 계산은 재사용했다. GUI에서 시험용 자동 마무리를 명시적으로 켠 경우에도 얼굴 참조를 강제한다. 얼굴 참조 없는 기존 직접 시험 API는 재현용으로 남아 있다.

## CPU 확인

신규 테스트는 선택한 한 장만 처리, 동일 프롬프트·얼굴 참조, 원본/마무리본 선택과 저장 SHA, 입력 변조 차단, 생성 도중 취소, 실패 후 원본·승인 유지, 실제 Qt 버튼과 작업 스레드, 마무리 후 꼬리 좌표, 비율 경로 차단을 확인한다.

관련 테스트 99개가 통과했다. 전체 회귀 결과는 아래 검증 결과에 기록한다.

실제 기존 시험의 seed 1690270743593249151로 GPU 없이 복사·프롬프트 복원·얼굴 SHA 확인을 수행했다. 기록은 `outputs/optional-finishing-gui-20261009/cpu-preflight.json`이다. 화면 캡처는 기존 시험 결과를 표시한 것이며 이번에 새로 생성한 이미지가 아니다.

## Claude GPU 재현 확인

목적은 선택 실행 경로가 기존 product-ip-03과 같은 결과를 내는지 확인하는 것이다. 생성 원본을 다시 만들지 않고 마무리만 한 장 실행한다. 새 출력 폴더를 쓰며 기존 시험 결과를 덮어쓰지 않는다.

1. 기존 `product_path/run-f2fa97bf/generation/seed-1690270743593249151/`의 raw.png와 run.json을 사용한다. 얼굴 참조는 run.json에 기록된 파일과 SHA 그대로다.
2. `StudioRuntime.from_environment()`를 확인한다. 운영 설정이 시험 당시와 다르면 임의로 바꾸지 말고 차이를 보고한다.
3. `OnePassCandidate(seed, raw_file, run_file, record)`를 만들고 `finish_selected(candidate, before_file, sha(before_file), 새_출력_폴더, runtime)`를 호출한다. 이번 재현에서는 before_file로 같은 raw.png를 쓴다. GUI는 현재 흰 배경 미리보기의 파일을 before로 전달하지만, 생성 입력은 양쪽 모두 동일한 raw다.
4. 반환 기록이 검토 대기인지 확인한다. `product-ip-03/run-f2fa97bf/generation/seed-1690270743593249151/`과 finished_hires.png, finished.png, product.png의 SHA를 각각 비교한다. 모든 단계가 같아야 재현 통과다. 하나라도 다르면 추가 생성하지 말고 실제 조건과 차이를 기록한다.
5. 단계별 실제 메모리·시간과 총 시간을 보고한다. 약 73초는 이전 시험값이며 이번 성능 보장이 아니다.

GPU 결과가 같아도 GUI에서의 사람 판정까지 끝났다는 뜻은 아니다. GUI에서 일반 생성 결과 한 장 → 고화질 마무리 → 원본 유지/마무리본 선택 → 결과 확인 → 저장을 확인한다. 마무리 후 꼬리 편집을 사용할 때는 기준 파일·SHA·크기가 마무리본으로 넘어갔는지도 확인한다.

## 머리 안쪽 선 작업의 현재 경계

옵션과 시험 실행기는 이미 작성돼 있다. R6 CPU 검사에서는 얼굴 마스크가 머리 영역 99.9%를 포함해 70% 중단 기준에 걸렸다. 기준을 완화하지 않았으며 GPU 시험은 보류다. 자세한 내용은 `HEAD_LINES_TRIAL_HANDOFF.md`에 있다. 라쿤·근육질 남성의 원본 비율 참고 + 후드 생성은 해당 시험의 비교 기준이며 이번 선택 마무리의 입력 대상은 아니다.

다음 할 일은 Claude의 한 장 GPU 재현 확인과 사용자의 실제 GUI 비교·저장 확인이다. 구현 당시에는 커밋·푸시를 하지 않았으며, 2026-10-09 후속 요청으로 커밋·푸시를 승인받았다.

## 검증 결과 (2026-10-09)

전체 CPU 테스트 1,983개 통과, 322.28초. 경고 2개는 기존 Pillow getdata 사용 중단 예고다. 신규 선택 마무리 테스트는 21개이며 모두 포함된다. `CUDA_VISIBLE_DEVICES`를 비우고 모델 오프라인 설정, Qt offscreen으로 실행했다.

실제 기존 입력 복사 검사는 통과했다. Qt 화면은 1024×700 작업실과 790×760 비교 창으로 렌더링해 배치를 확인했다. offscreen 캡처의 한글 글꼴은 기존 Windows Malgun Gothic 파일을 검사 스크립트에서 등록했다. 운영 글꼴 설정은 바꾸지 않았다. 캡처는 `outputs/optional-finishing-gui-20261009/workspace.png`, `comparison.png`에 있다.
