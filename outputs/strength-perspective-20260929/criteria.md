# 원근 자세 세기 시험 (하이앵글) — 사전 등록

작성: 2026-09-29, Claude. 생성 전에 잠근다. 판정자는 strength-5pose 결과를 봤다(완전 블라인드 아님).

## 질문
strength-5pose 에서 하이앵글은 1.2 에서 붕괴는 줄었지만(3→1) 관절 목표 근접이 6→1 로 떨어졌다. 1.2 와 1.5 사이 세기가 붕괴를 늘리지 않고 관절 정확도를 되찾는가?
제품에서는 자세 태그(from_above 등)로 원근 자세를 구분해 이 세기를 쓸 수 있다.

## 구성
strength-5pose 와 같은 코드·프롬프트(C4 하이앵글)·골격·얼굴, 골격 0~10단계, 얼굴 IP 11단계부터. 캐릭터 2 × seed 209210001~209210006.
- H13: 세기 1.3 (12장 새로), H14: 세기 1.4 (12장 새로)
- S12(1.2), S15(1.5) 하이앵글 24장은 strength-5pose 결과 재사용.
48장 전부 새 블라인드 시트로 다시 라벨한다(이번 시험의 S12·S15 값은 새 라벨).

## 측정
붕괴(있음/없음, strength-5pose 정의), V1 하이앵글 자세(위에서 내려다본 시점 + 폰/주머니 손: 예/부분/아니오), VG, VI, VX. DWPose 8관절 목표 거리(< 0.15 근접).

## 판정
- PX(X) 채택 후보: X 근접 >= S12 근접 + 3, X 붕괴 <= S12 붕괴 + 1, X 의상 "예" >= S12 의상 "예" − 2, X 자세 "예" >= S12 자세 "예" − 2.
- 둘 다 성립하면 낮은 세기(1.3) 우선. 둘 다 불성립이면 "하이앵글은 1.2 유지(관절 정확도 대신 안정성)".
- 한계: 하이앵글 자세 이미지 1장뿐 — 원근 자세 일반 규칙이 아니라 이 자세의 경향.
