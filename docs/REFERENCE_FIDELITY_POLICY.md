# 참조 동일성 정책

상태: 검토 초안  
효력: 사용자 승인 전까지 문서 제안이며 런타임 차단 정책으로 사용하지 않는다.

## 용어

- `reference_fidelity`: 출력이 원본 캐릭터와 의상의 승인 특징을 재현한 정도
- `repeat_consistency`: 동일 조건의 여러 출력 사이에서 승인 특징이 유지되는 정도
- `mask_alignment`: 두 좌표계에서 재검출한 영역의 위치·면적·형태 정렬 상태
- `anchor`: 사용자가 참조 동일성을 확인하고 후속 생성 기준으로 승인한 이미지
- `unresolved`: 증거 부족, 검출 충돌 또는 관측 불가능으로 판정하지 못한 상태

`mask_alignment=pass`를 `reference_fidelity=pass`로 해석하지 않는다.

## P1. 입력 역할 격리

캐릭터 참조는 캐릭터 정체성만, 의상 참조는 의상 디자인만 제공한다. 의상 이미지에 포함된 사람 특징과 캐릭터 이미지의 기존 의상은 서로의 조건으로 전달하지 않는다.

## P2. 동일성 우선

최초 Anchor의 참조 동일성이 승인되기 전에는 반복 일관성 개선 기능을 공통 생성 경로에 넣지 않는다. 잘못된 Anchor를 반복하는 결과를 성공으로 계산하지 않는다.

## P3. 평가 축 분리

다음 결과를 독립 기록한다.

- 캐릭터 동일성
- 의상 동일성
- 참조 누설
- 공간 정렬
- 기술 무결성
- 반복 일관성

전체 평균 하나로 실패 항목을 상쇄하지 않는다. 대표 점수가 필요하면 각 축을 함께 표시하고 최저 축과 `unresolved` 개수를 별도로 표시한다.

## P4. 진단과 자동 차단 분리

자동 차단은 다음에 한정한다.

- 파일·해시·승인 조건 불일치
- NaN, 디코딩 실패 또는 명백한 픽셀 손상
- 다중 인물 또는 명백한 신체 구조 붕괴
- 사용자가 금지한 조건의 명백한 충돌

낮은 DINO·CLIP·색상·마스크 점수만으로 이미지를 숨기거나 폐기하지 않는다. 결과와 진단을 사용자에게 보여준다.

## P5. 불확실성 보존

- 검출되지 않음은 자동 부재가 아니다.
- `unresolved`는 프롬프트·태그·보호 마스크로 자동 승격하지 않는다.
- 귀·꼬리·장신구처럼 클래스와 위치가 겹치면 원시 후보를 보존하고 강제로 한 클래스를 선택하지 않는다.
- 사람 귀·동물귀·꼬리·장신구 후보가 전경 대비 부위별 면적 상한을 넘으면 `unresolved`로 기록하고 자동 조건화하지 않는다. 원시 박스와 마스크는 진단용으로 보존한다.
- 작은 부위는 고해상도 ROI 재검증 후에도 불확실하면 2-Pass 유도 후보로만 기록한다.
- 승인 태그나 확인된 검출이 없는 선택 부위는 unresolved_skipped로 기록하고, 해당 마스크 없이 identity·garment 경로를 계속한다. 선택 부위가 없다는 이유만으로 생성 전체를 실패시키지 않는다.

## P6. 좌표계 분리

참조 이미지 마스크를 생성 결과 좌표에 직접 주입하지 않는다. 출력 이미지에서 마스크를 다시 검출한다. 참조 마스크와 출력 마스크의 비교는 진단 전용이다.

## P7. 지표 사용 제한

- CLIP-I: 넓은 의미·인상 보조값
- Masked DINO: 마스크 내부 주체 세부 유사도 후보
- 마스크 IoU/Dice: 공간·형태 정렬
- 색상 거리: 주요 색 분포
- 구조·토폴로지: 규칙 기반 부품 관계
- 사람 판정: 최종 Anchor 승인 근거

어떤 단일 지표도 확률, 정확도 또는 90% 반영을 의미하지 않는다. 임계값은 사람이 라벨링한 고정 검증 세트에서 보정하기 전까지 진단 기본값이다.

비교 대상 마스크 중 하나라도 부위별 최소 픽셀 수 또는 캔버스 면적 비율보다 작으면 IoU·Dice·containment를 산출하지 않고 `not_measurable`로 기록한다. 낮은 유사도와 측정 실패를 같은 숫자로 표시하지 않는다. 얼굴 검출 보조 박스와 헤어 GroundingDINO+SAM2 관측 마스크는 측정 ROI이며 semantic segmentation 정확도로 해석하지 않는다. 이 관측 마스크는 Base·최종 결과 좌표에서 각각 다시 검출하며 생성 마스크로 자동 주입하지 않는다.

최종 이미지에서 미승인 의상 부위가 검출되면 동일 검출기를 승인 Base에도 적용한다. Base와 최종 이미지 모두에 있으면 inherited_from_base, Base에는 없고 최종 이미지에만 있으면 introduced_by_refinement로 분리한다. 최종 충돌 판정은 유지하되 최초 발생 단계를 숨기지 않는다.

## P8. 도메인 적용 제한

InstantID, PhotoMaker, PuLID 같은 얼굴 ID 방법은 실사 얼굴 중심 근거다. 애니·수인·SD·비인간 캐릭터에서 별도 A/B 검증 전에는 기본 계약으로 적용하지 않는다.

VTON 방법은 사람 사진과 정형 의상 데이터의 편향이 있다. 남녀 교차 착용, 수인, 과장 체형, 연결 의상, 의상만 있는 이미지에 대해 별도 평가하기 전에는 자동 성공을 주장하지 않는다.

## P9. Anchor 봉인

승인 Anchor는 이미지뿐 아니라 다음을 함께 봉인한다.

- 원본 참조 해시
- 마스크와 분석 기록
- 승인 태그·프롬프트
- Base와 최종 결과
- 모델·Seed·해상도·스텝·강도
- 항목별 동일성·누설 진단

Anchor 승인과 학습 자료 승인은 별도다.

## P10. 후속 일관성 생성

후속 생성은 원본 두 장과 Anchor를 모두 비교 기준으로 사용한다. Anchor만 사용해 원본과의 차이를 잊지 않는다. 한 실행에서는 자세·표정·배경 중 한 핵심 조건만 바꾼다.

## P11. 학습 자료 승격

- 사용자가 Anchor로 승인한 결과만 후보가 된다.
- 캐릭터 정체성, 의상, 포즈를 처음부터 한 LoRA에 함께 학습하지 않는다.
- 정면 한 장으로 보이지 않는 측면·후면 특징을 정답으로 간주하지 않는다.
- 승인된 다중 시점 자료가 모이기 전에는 DreamBooth·LoRA 학습을 공통 제품 경로에 넣지 않는다.

## P12. 변경과 회귀

- 새 기법은 기존 경로와 같은 입력·Seed로 A/B 비교한다.
- 한 번에 하나의 핵심 조건만 바꾼다.
- 특정 캐릭터 한 장을 통과시키는 예외 규칙을 공통 계약에 추가하지 않는다.
- 동일성 개선이 다른 캐릭터·체형·의상에서 회귀하면 해당 변경만 되돌린다.

## 승인 전 필요한 증거

1. 사람 라벨이 있는 고정 참조 동일성 검증 세트
2. 캐릭터 유형과 의상 유형별 최소 표본 수
3. Masked DINO·CLIP-I·구조·색상 지표와 사람 판정의 상관관계
4. 동일 입력 다중 Seed의 평균, 최저값, 표준편차, `unresolved` 비율
5. 캐릭터 기존 의상과 의상 이미지 인물 특징의 누설률
6. 실패 이미지를 숨기지 않은 전체 결과 기록

이 증거가 없으면 정책 상태는 `diagnostic_only`로 유지한다.
