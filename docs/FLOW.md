# 하향식 입력부터 결과까지의 흐름

이 문서는 GUI에서 후보 이미지 한 장을 만들고 사용자가 저장을 결정할 때까지의 흐름을 네 개의 큰 블록으로 나눕니다. 오류가 발생하면 코드를 바로 고치기 전에 어느 블록의 책임인지 먼저 확인합니다.

## 전체 흐름

```text
[1. 사용자 입력]
기준 이미지 + 화면 범위 + 선택 의상 이미지·종류
          ↓
[2. 데이터 가공]
검사 + 크기 결정 + 생성 문장 준비 + 시드 준비
          ↓
[3. AI 모델 실행]
준비된 요청으로 후보 이미지 한 장 생성
          ↓
[4. 결과 출력]
메모리 보관 + 사용자 승인·거절 + 승인 결과 저장
```

각 블록은 다음 블록이 바로 사용할 수 있는 결과를 만들어서 전달합니다. 다음 블록이 앞 블록의 계산을 다시 하지 않습니다.

## 1. 사용자 입력 블록

사용자가 화면에서 직접 선택하는 값만 받습니다.

- 캐릭터 기준 이미지 한 장
- 화면 범위: 전신, 상반신 또는 얼굴 중심
- 선택 입력: 의상 참조 이미지와 상의·하의·드레스·전신 의상 종류

이 블록은 입력 여부를 화면에 보여주지만 다음 작업은 하지 않습니다.

- 이미지 크기 결정
- 생성 문장과 제외 문장 조립
- 시드 생성
- 모델 실행
- 결과 파일 저장

이 블록의 출력은 **캐릭터 생성 입력(CharacterGenerationInput)**입니다.

포함하는 값:

- 기준 이미지 경로
- 선택한 화면 범위
- 선택한 경우 의상 이미지 경로와 의상 종류

## 2. 데이터 가공 블록

사용자 생성 요청을 AI 모델이 바로 실행할 수 있는 형태로 바꿉니다.

이 블록에서만 다음 작업을 수행합니다.

- 기준 이미지 파일과 선택값 검사
- 선택한 화면 범위에 맞는 크기와 구도 문구 결정
- 화면 범위에 맞는 생성 문장과 제외 문장 준비
- 새로운 후보에 사용할 시드 생성
- 모델 설정과 사용자 선택을 한 요청으로 묶기
- 크기, 시드와 필수 값의 마지막 검사

이 블록의 출력은 **캐릭터 생성 실행 요청(CharacterGenerationRequest)**입니다.

포함하는 값:

- 기준 이미지
- 화면 범위
- 가로와 세로
- 생성 문장과 제외 문장
- 시드
- 생성 단계 수와 그림체 적용 강도
- 사용할 모델 정보

이 블록은 GPU를 사용하지 않고 이미지를 저장하지 않습니다. 비율과 크기 규칙을 바꿀 때는 이 블록만 수정합니다.

## 3. AI 모델 실행 블록

- 선택한 경우 CatVTON 별도 프로세스로 의상 합성
- 의상 마스크에서 얼굴·머리·노출 신체·손발·장신구 보호 영역 제외
- 허용 의상 픽셀만 기본 캐릭터에 합성
- 얼굴·손 부분 보정
- 각 보정 전후 결과를 메모리로 반환
실행 준비 요청을 받아 후보 이미지 한 장을 생성합니다.

이 블록에서 수행하는 작업:

- 기본 이미지 모델 준비
- 기준 이미지 특징 전달 기능 연결
- 준비된 값으로 모델 한 번 실행
- 실행 시간과 GPU 사용 결과 수집
- 생성 이미지를 시스템 메모리로 반환

이 블록의 출력은 **캐릭터 생성 후보(CharacterGenerationCandidate)**입니다.

포함하는 값:

- 메모리에 있는 생성 이미지
- 사용한 시드와 화면 범위
- 모델과 생성 설정
- 생성 시간과 실행 상태

이 블록은 화면 비율을 계산하지 않습니다. 사용자 승인 여부를 판단하지 않으며 PNG와 JSON 파일도 저장하지 않습니다.

## 4. 결과 출력 블록

생성 후보를 사용자에게 보여주고 이후 행동을 처리합니다.

- 생성 후보를 시스템 메모리에 임시 보관
- 사용자의 승인 또는 거절 처리
- 거절 시 최대 3회 안에서 재생성 여부 확인
- 승인 후 저장 여부를 다시 확인
- 저장 승인 시 PNG와 같은 이름의 JSON 저장
- 저장 실패 시 후보를 메모리에 유지하고 다시 저장 처리

승인된 결과의 기본 저장 위치는 다음과 같습니다.

```text
outputs/approved/YYYY-MM-DD/
```

저장 승인 전에는 이미지 파일이나 결과 JSON을 만들지 않습니다.

## 오류가 발생했을 때 확인할 블록

| 보이는 문제 | 먼저 확인할 블록 |
|---|---|
| 이미지 선택이나 화면 버튼이 동작하지 않음 | 사용자 입력 |
| 전신인데 크기·문장·시드가 잘못됨 | 데이터 가공 |
| GPU 오류나 이미지 생성 자체가 실패함 | AI 모델 실행 |
| 승인 상태, 파일명 또는 PNG·JSON 저장이 잘못됨 | 결과 출력 |

한 문제를 고치기 위해 여러 블록에 같은 계산이나 예외 처리를 복사하지 않습니다.

## 현재 코드와 목표 구조의 차이

현재 코드는 다음 책임이 아직 섞여 있습니다.

- `gui_main.py`가 화면 처리와 함께 크기, 생성 문장과 시드를 준비합니다.
- `GenerationWorker`가 모델 실행 전에 결과 폴더와 JSON을 만듭니다.
- `generator.py`가 모델 실행과 이미지·JSON 저장을 함께 처리합니다.

목표 구조에서는 데이터 가공을 별도 역할로 옮기고, 모델 실행은 메모리에 있는 후보만 반환하며, 결과 출력은 사용자 저장 승인 뒤에만 파일을 만듭니다.

이 문서 변경은 목표 구조를 확정하는 작업입니다. 실제 Python 파일 분리와 동작 변경은 별도 구현과 테스트를 통과한 뒤 완료로 기록합니다.
## 참조 화질과 세부 보정을 포함한 현재 흐름

```text
[기준 이미지 선택]
        ↓
[규칙 기반 화질 검사]
   ├─ 통과 → 원본 승인
   └─ 부족 → 확대 복원 → 원본/보정본 사용자 비교
                              ├─ 승인 → 보정본 사용
                              └─ 거절 → 생성 중단
        ↓
[Animagine + IP-Adapter 후보 생성]
        ↓
[YOLO 얼굴·손 위치 탐지]
   ├─ 못 찾음/실패 → 생성 원본 유지 + 원인 기록
   └─ 찾음 → 작은 허용 영역만 Inpaint
                    ↓
          [마스크 밖 변경 검사]
             ├─ 변경 있음 → 보정 폐기
             └─ 변경 없음 → 보정 전후 사용자 비교
        ↓
[후보 승인 또는 거절]
        ↓
[저장 승인한 결과만 PNG와 JSON 기록]
```

화질 점수, 탐지와 부분 보정은 사용자의 최종 품질 판단을 대신하지 않습니다. 규칙과 AI 보조가 실패하면 원본 후보로 돌아갈 수 있어야 하며, 승인 전 이미지는 파일로 저장하지 않습니다.


## 의상 참조 연결을 위한 보호 흐름

[기본 캐릭터 후보]
        +
[사용자가 승인한 의상 참조]
        +
[의상 영역 마스크 + 신체 보호 마스크]
        ↓
[의상 합성 모델의 임시 출력]
        ↓
[의상 허용 영역 픽셀만 기본 캐릭터에 합성]
        ↓
[얼굴·머리·손·발·피부·배경 픽셀 불변 검사]
   ├─ 한 픽셀이라도 변경 → 후보 폐기
   └─ 변경 없음 → 사용자 비교 후보

현재 코드는 CatVTON 별도 실행, SCHP·DensePose 마스크, 보호 영역 제외, 제한 합성과 픽셀 검사를 GUI에 연결했습니다. CatVTON 환경이 없거나 실행에 실패하면 기본 생성 후보로 복구합니다. 합성 모델의 전체 출력을 직접 다음 단계로 넘기지 않는 것이 핵심 규칙입니다.
