# Qwen 좌표 보정과 꼬리 시험 인수인계

2026-10-05, Codex. 사용자가 좌표 보정 구현과 기존 결과 확인을 승인한 뒤 수행했다. 새 GPU 이미지 생성 없이 운영 후처리만 수정했다.

## 적용한 변경

기존 미리보기는 Qwen 원본 800×1312를 736×1207로 축소하고 위 12px·아래 13px 흰 여백을 넣었다. 승인 기반 736×1232와 비교하면 세로 비율과 위치가 달라졌다.

`genai_lab/qwen_pose_edit.py`의 `product_preview`는 이제 승인 기반의 실제 크기로 직접 리사이즈한다. 크기를 736×1232로 고정하지 않는다. LANCZOS는 유지하며 raw 파일을 덮어쓰는 호출은 거부한다.

- `make_request`: 승인 기반의 실제 크기를 `basis_size`로 기록한다.
- `run_pose_edit`: 실행 전에 승인 이미지 바이트의 SHA와 크기를 확인한다. 요청 크기와 다르면 worker를 시작하지 않는다. 이전 요청에 크기 필드가 없으면 승인 이미지에서 읽는다.
- 기록은 부모의 `launcher.json`에 남긴다. `product_transform`에 변환 버전 2, 원본·목표 크기, 배율, 여백, 보간 방식과 픽셀 중심 좌표식을 기록하고 `basis_sha256`도 남긴다. worker 소유 `run.json`은 변경하지 않았다.
- 새 요청 메타데이터로 request SHA는 달라진다. 모델·프롬프트·시드·Qwen 출력 크기·생성 인자는 바꾸지 않았다. 새 product SHA는 달라질 수 있다.
- GUI는 기존에 기반·raw·product를 읽고 비율 유지 축소로 표시하므로 별도 연결 변경은 없었다. 자세 GUI 신규 연결도 하지 않았다.

리사이즈는 표시 좌표를 복원한다. 모델이 생성 과정에서 바꾼 신체 위치·꼬리 형태를 역으로 복원하는 기능은 아니다. 사용한 API는 [Pillow Image.resize](https://pillow.readthedocs.io/en/stable/reference/Image.html#PIL.Image.Image.resize)다.

## 코드 검증

Windows 기존 운영 환경에서 실행했다. 코드 작성은 Linux에서 했다. 설치·다운로드 없음.

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:QT_QPA_PLATFORM = 'offscreen'
$env:CUDA_VISIBLE_DEVICES = ''
& 'D:\genai-cache\venv\Scripts\python.exe' -m pytest -p no:cacheprovider tests/ -q
```

- 대상 테스트: 60 passed in 8.72s.
- 전체 회귀: **1544 passed, 2 warnings in 227.58s**. 종료 코드 0.
- 기반 736×1232 / 936×2048 / 1024×1024의 위·중앙·아래 합성 점, 총 9개에서 복원 오차 ±1px 이내.
- raw SHA 보존, 흰 여백 제거, 잘못된 크기·raw 덮어쓰기 차단, 이전 요청 호환, 가짜 worker의 사용자 검토 연결을 확인했다.
- 실제 GPU 재실행과 사용자 수동 GUI 클릭 검증은 수행하지 않았다.

## 꼬리도 별도로 비교한 결과

위 8장과 B5 관련 3장, 총 11개의 기존 결과를 CPU로 비교했다. 서로 연관된 결과이므로 독립적인 11개 성공률 시험이 아니다.

- 고양이과의 굵은 꼬리, 참조에 없던 띠무늬, 일부 라쿤 결과의 큰 여분 꼬리 같은 형태는 보정 후에도 남았다.
- 나선형 끝이 있었던 카멜레온 결과는 그대로 유지됐고, 없던 결과에는 새로 생기지 않았다.
- 전신 결과의 배율 변화는 기존 표시 대비 가로 1.0000배·세로 1.020713배다.
- 330×560 꼬리 영역 편집 결과 두 개는 구형 표시를 같은 기반 좌표로 환산하면 가로 약 1.004093배·세로 1.0000배다. 이 차이로 굵은 꼬리가 가늘어지지는 않았다.
- 원본·입력·기록 SHA 11/11 유지. 지정 경로에 과거 복원본이 있는 9개는 9/9 픽셀 동일했다.

ROI는 꼬리 주변 사각형으로 몸·옷·배경이 섞인다. 꼬리 실측 굵기나 면적을 자동 분할로 측정한 것은 아니다. 육안 판정은 Codex의 비블라인드 잠정 관찰이며 가려진 끝은 미측정이다.

## 자동 인식 시험에서 확인한 별도 문제

이 내용은 운영 코드에 연결하지 않은 시험 결과다. 좌표 보정과 구분한다.

1. 기존 Qwen 편집 모델의 캐시 텍스트 인코더를 분석에 재사용했다. 설명 2회·비교 3회에서는 없는 무늬 추가와 굵기 관계 반전이 나왔다. 기존 DINO+SAM2 분할 2회도 옷 조각 포함 또는 잘못된 부위 선택으로 실패했다. 사전 기준에 따라 편집 생성은 0회였다.
2. 후속 기초 대조 4회 중, 동일 고양이과 참조 두 장과 동일 라쿤 참조 두 장 모두 없는 차이를 만들어 수정 지시를 했다. 동일 이미지 대조 통과 0/2. CPU로 재계산한 동일 이미지의 전처리 텐서는 같았다.
3. B5 입력 순서·역할 번호를 교환해도 더 굵게 하라는 잘못된 방향을 유지했다. B3는 이전과 다른 수정 지시를 냈다.

이는 현재 시험용 분석 구성을 자동 보정 지시로 바로 연결할 근거가 부족하다는 결과다. 순정 Qwen2.5-VL-Instruct의 평가가 아니며, 질문의 유도·체크포인트 용도·전처리 해상도·양자화 중 원인을 분리하지 않았다. Qwen 이미지 편집 내부에서도 같은 오류가 일어났다고 확정하지 않는다.
