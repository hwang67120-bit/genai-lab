# 피부색 기반 얼굴 분리 수정과 CPU 확인

R6 머리 선 준비를 막던 얼굴 분리를 피부색 방식으로 바꿨고 CPU 사전 검사가 통과했다. 생성 이미지는 새로 만들지 않았다. 피부색 보정이나 다른 캐릭터 일반화가 검증됐다는 뜻은 아니다.

## 바뀐 처리

`head_lines.prepare_head_lines`는 기본으로 `skin_color_v1`을 사용한다. 코 좌표를 반올림하고, 코 주변 7×7 RGB 픽셀을 OpenCV 8비트 Lab로 변환한 후 L은 0~100, a·b는 0 중심으로 환산한다. 각 성분 중앙값과 ΔE76이 12 미만인 머리 영역 픽셀을 후보로 삼는다.

코 픽셀이 속한 8-연결 성분만 선택하고, 바깥 윤곽을 채워 눈·입 구멍을 메운다. 기존 2픽셀 확장과 머리 영역 제한, 빈 얼굴 및 70% 초과 중단 규칙은 그대로다. 코가 후보에 없으면 사유와 측정값을 남기고 중단하며 SAM2로 자동 전환하지 않는다.

기존 SAM2 방식은 `--face-method sam2`로 명시적으로 비교할 수 있다. 기본 CPU 준비에서는 SAM2를 로드하지 않는다. Canny·잡음 제거·선 두께와 기존 골격·얼굴 참조·생성 조건은 바꾸지 않았다. none은 인식을 실행하지 않는다. all 선 픽셀은 얼굴 분리 방식과 무관하며 기존 방식과 같음을 검사했다. 미리보기 색상 및 기록 SHA는 분리 방식이 바뀌었으므로 달라질 수 있다.

## Claude 다음 작업

먼저 위 미리보기를 사용자에게 보여 준다. 확인을 받은 뒤에만 다음 명령으로 R6 hair/all 두 조건, seed 두 개씩을 실행한다. 기존 BASE는 재사용하며 새 생성은 4장이다.

```powershell
& 'D:\genai-cache\venv\Scripts\python.exe' -B '\\192.168.0.109\win_g\genai-lab\scripts\head_lines_trial.py' --prepared '\\192.168.0.109\win_g\genai-lab\outputs\hair-lineart-design-20261008\codex-cpu-r6-skin-01' --review-sha 'ebde57d973f3c824daf7b41776c5e2e7461d305165393c223436ac1719cf5827' --run --output '\\192.168.0.109\win_g\genai-lab\outputs\hair-lineart-design-20261008\gpu-r6-skin-01'
```

원본·얼굴·골격·seed·프롬프트·어댑터 설정은 고정한다. 머리 모양, 이마·눈 주변의 불필요한 선, 얼굴 동일성, 의상 영향을 따로 판정한다. R6만으로 라쿤·근육질 남성까지 통과했다고 판단하지 않는다. 준비 뒤 코드나 파일이 바뀌면 잠금이 중단시키므로 새 CPU 준비와 재확인을 한다.

## 근육질 남성 피부색 보정과의 구분

제공된 측정표는 색 차이가 있다는 근거이지 `dark skin` 태그가 원인이라는 대조 시험 결과가 아니다. a=22→9~13은 약 41~59%, b=21→14~18은 약 14~33% 감소다. 둘 다 절반 줄었다고 표현하지 않는다. 이 값은 색 좌표의 변화이며 지각되는 색의 강도가 같은 비율로 감소했다는 의미도 아니다.

현재 생성 호출은 얼굴 참조 이미지를 전달하지만 몸 피부색을 측정값과 일치시키는 조건을 전달하지 않는다. 이를 단순히 얼굴 참조가 얼굴에만 작용한다고 단정하지 않는다.

이번 마스크는 머리 안에서 코와 연결된 얼굴을 고르는 용도다. 전신 피부 선택에 그대로 재사용하면 떨어진 팔·다리 또는 색이 달라진 피부가 빠질 수 있다. 특히 제공된 ΔE 12~23이 같은 ΔE76 척도로 측정된 값이라면, 생성 피부를 원본 표본과 ΔE76<12 규칙으로 찾을 때 보정할 피부부터 제외될 수 있다. 측정식이 다른 경우 숫자를 직접 비교하지 않는다.

추천하는 별도 CPU 시험은 기존 4장의 생성 이미지에서 피부 영역을 먼저 확인한 뒤 원본 피부색을 목표로 색만 옮기는 것이다. 첫 시험은 밝기 L과 명암을 유지하고 a·b의 차이를 보정해 색 변화 효과부터 분리한다. 피부 밖 픽셀 불변, 피부 마스크 누락·오포함, 피부 색 차이, 경계 얼룩을 따로 확인한다. 밝기와 얼굴·몸의 조명 차이까지 없애는 시험은 함께 섞지 않는다. 이 보정은 아직 구현·실행하지 않았다.

다음 할 일: 사용자에게 R6 머리 선 미리보기를 확인받은 후 Claude가 GPU 시험을 진행한다. 전신 피부색 보정은 별도 마스크 검증부터 시작한다.
