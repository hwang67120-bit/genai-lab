# 참조 동일성 Anchor 생성 시나리오

상태: 검토 초안  
범위: 캐릭터 참조 한 장과 의상 참조 한 장에서 최초 승인 Anchor 한 장을 만드는 과정  
비범위: Anchor 이후의 연속 장면·포즈 일관성 생성

## 성공 정의

성공은 출력 이미지가 예쁘거나 전체 CLIP 점수가 높은 상태가 아니다. 다음 조건이 각각 확인된 상태다.

- 캐릭터 참조에서 승인한 얼굴·헤어·체형·선택적 특징이 유지된다.
- 의상 참조에서 승인한 상의·하의·전신 의상·신발·장식의 구조와 색이 유지된다.
- 캐릭터 참조의 기존 의상이 남지 않는다.
- 의상 참조에 포함된 인물의 얼굴·헤어·체형·포즈가 들어오지 않는다.
- 계산하지 못한 항목은 `unresolved`로 공개된다.
- 사용자가 결과를 동일성 Anchor로 승인한다.

## 단계

### A1. 요청 격리

- 새 `RunContext`를 만든다.
- 이전 캐릭터, 의상, 프롬프트, 마스크, 어댑터 상태를 상속하지 않는다.
- 캐릭터와 의상 입력의 경로·크기·SHA-256을 기록한다.

실패 반환: `input_invalid`, `role_collision`, `request_isolation_failed`

### A2. 캐릭터 참조 분석

독립 분석 항목:

- 얼굴과 눈
- 헤어 전체 실루엣, 앞·옆·뒤·묶음·Ahoge의 관측 가능 상태
- 체형과 신체 비율
- 사람 귀, 동물귀, 꼬리
- 캐릭터 고유 장신구
- 기존 의상 영역

검출되지 않음은 자동으로 `absent`가 아니다. 위치·클래스 충돌이 있거나 작은 픽셀이라 판단할 수 없으면 `unresolved`다. 사람 귀·동물귀·꼬리·장신구 후보가 전경 대비 부위별 면적 상한을 넘으면 원시 후보만 보존하고 자동 조건화하지 않는다.

SCHP 얼굴 마스크가 측정 최소값보다 작거나 마스크 경계 박스가 얼굴 상한을 넘으면 별도 얼굴 검출 ROI를 한 번 관측한다. 신뢰도와 면적 범위를 통과한 최고 후보 한 개만 얼굴·identity ROI에 합치며, 실패하면 추정 영역을 만들지 않고 `unresolved`로 둔다. 생성 입력에서 복구된 얼굴 ROI와 의상 마스크가 겹치면 얼굴 ROI를 의상 영향 영역에서 제외한다.

헤어는 Base·최종 결과에서 머리 ROI를 확대해 GroundingDINO 후보를 SAM2로 관측한다. 이 마스크는 A6·A8 측정 전용이며 생성 조건으로 자동 주입하지 않는다. 관측 실패 시 기존의 의미가 다른 파서 마스크로 조용히 대체하지 않고 `not_measurable`로 둔다.

### A3. 의상 참조 분석

의상 이미지를 인물 이미지와 같은 방식으로 통째로 인코딩하지 않는다.

- 상의
- 하의
- 전신 연결 의상
- 겉옷
- 양말·레깅스
- 신발
- 장신구
- 색상·소재·패턴·장식

의상 참조의 인물 얼굴·헤어·체형·포즈는 전달 금지 항목으로 기록한다. 상의와 하의가 연결됐는지 판단할 수 없으면 `unresolved_topology`로 남긴다.

### A4. 사용자 입력 승인

사용자가 확인할 항목:

- 원본 두 장과 역할
- 부위별 마스크
- 추출 태그와 프롬프트
- `present / absent / unresolved`
- 의상 토폴로지
- 생성에 전달되는 조건과 제외되는 조건

승인하지 않은 관측값은 생성 조건으로 승격하지 않는다.

### A5. 자연스러운 캐릭터 Base 생성

Base의 목적은 캐릭터 정체성·체형·기본 구도를 확보하는 것이다.

- 캐릭터 조건만 사용한다.
- 목표 의상 이미지와 목표 의상 태그는 Base에서 제외한다.
- 원본 캐릭터 이미지는 Img2Img Anchor로 사용한다.
- 강한 부위 마스크 덮어쓰기나 픽셀 붙이기를 하지 않는다.
- 승인 태그나 확인된 검출이 없는 귀·꼬리·장신구는 unresolved_skipped로 기록하고 해당 조건 없이 진행한다.

### A6. Base 독립 재검증

Base가 생성된 뒤 다음 순서로 분석한다.

1. 캐릭터 참조를 현재 분석기로 다시 검증한다.
2. Base를 Base 좌표에서 독립 검증한다.
3. 두 마스크의 공간 정렬을 교차 진단한다.
4. 각 비교 마스크가 최소 픽셀 수와 최소 캔버스 면적 비율을 충족하는지 검사한다.
5. 측정 가능한 항목에만 IoU·Dice·containment를 계산한다.
6. 마스크 정렬과 캐릭터 동일성을 별도 항목으로 기록한다.
7. 승인 의상에 없는 하의·양말류를 Base 의미 검출기로 검사해 의상 중립화 실패를 기록한다.

얼굴·헤어·identity·전경 중 하나가 `not_measurable`이면 A7 자동 진행을 차단하고 새 Base Seed 또는 검출 복구 대상으로 돌린다. `review`인 핵심 부위도 사용자가 승인하거나 고정 검증 세트로 임계값을 보정하기 전에는 자동 진행하지 않는다. 공간 정렬 PASS는 캐릭터 동일성 PASS가 아니다. Base 의상 중립화 실패는 base_garment_contamination으로 별도 기록하며, 최종 의상 검증에서 처음 생긴 누설과 구분한다.

### A7. 목표 의상 적용

승인 Base와 의상 참조를 사용한다.

- 상·하의·전신·신발·장신구 조건을 독립 전달한다.
- 의상 고수준 의미와 저수준 색·패턴·소재를 분리 기록한다.
- 캐릭터 얼굴·헤어·체형은 의상 경로에 넣지 않는다.
- 의상 이미지 인물의 특징은 금지 조건으로 유지한다.
- 조건 강도는 시간·공간·단계 유도로 올리며 한 번에 최대 강도로 고정하지 않는다.

### A8. 참조 동일성 평가

#### 캐릭터 동일성

- 얼굴: Masked DINO, CLIP-I 보조값, 눈·얼굴 구조 진단
- 헤어: 전체 실루엣, 길이, 앞·옆·뒤 구조, 색상
- 체형: 키 비율, 어깨·허리·골반·사지 비율
- 선택적 특징: 귀·꼬리·고유 장신구의 상태와 위치

#### 의상 동일성

- 토폴로지: 상·하의, 전신 연결, 겉옷, 신발
- 실루엣과 길이
- 주요·보조 색상
- 패턴·소재·장식
- 누락·중복·새 부품 생성 여부

#### 누설 검사

- 기존 캐릭터 의상 잔존
- 의상 참조 인물의 얼굴·헤어·체형 유입
- 승인하지 않은 성별·동물 특징·장신구 생성
- 미승인 하의가 Base에 이미 있었는지, FLUX 정밀화에서 새로 생겼는지의 단계 전이

한 항목이 계산 불가하면 전체 평균에서 제외해 점수를 높이지 않는다. 마스크가 없거나 최소 면적보다 작아 비교 자체가 무의미하면 `not_measurable`, 충분한 마스크는 있으나 의미 판정이 불확실하면 `unresolved`로 구분한다. Base와 최종 결과에 같은 미승인 하의가 있으면 inherited_from_base, 최종 결과에만 있으면 introduced_by_refinement로 기록한다. 강한 성별 충돌은 하드 프롬프트를 자동 주입하지 않고 refinement_requested의 명시적 진단 대상으로 올린다.

### A9. 사용자 Anchor 승인

사용자 선택:

- `anchor_approved`: 최초 동일성 Anchor로 봉인
- `refinement_requested`: 현재 결과와 Base를 보존하고 선택 부위만 다시 유도
- `rejected`: 원인에 따라 입력 분석 수정 또는 새 Seed 생성

Anchor 승인 시 저장:

- 원본 두 장과 해시
- Base와 최종 이미지
- 모든 마스크·태그·프롬프트
- 모델·Seed·해상도·스텝·강도
- 항목별 동일성 진단
- 사용자의 승인 시각과 결정

## Anchor 이후 일관성 단계

Anchor가 승인된 뒤에만 실행한다.

1. 원본 캐릭터 참조와 원본 의상 참조를 계속 유지한다.
2. Anchor를 세 번째 시각 참조로 추가한다.
3. 한 번에 자세·표정·배경 중 하나만 변경한다.
4. 결과를 원본 두 장과 Anchor 모두에 비교한다.
5. Anchor의 오류가 복제되지 않았는지 누설 검사를 반복한다.
6. 정면·측면·후면 승인 이미지가 쌓이면 별도 학습 실험을 검토한다.

## 최소 검증 행렬

Anchor 생성 정책을 채택하기 전에 다음을 같은 설정에서 시험한다.

- 캐릭터 유형: 일반 여성, 일반 남성, 근육형, SD, 수인
- 의상 유형: 상·하의 분리, 전신 연결, 겉옷, 레깅스, 신발 포함
- 자세: 정면, 팔 올림, 신체 일부 가림
- 각 조합: 최소 5 Seed

현재 네 장의 서로 다른 결과는 범용성 사례이며 반복 일관성 표본으로 사용하지 않는다.
