## 해석
CPU에서 확인한 '작은 조각의 칼날 끝도 후보로 유지'는 GPU 마스크에서도 관찰됐다.
부동소수점 연산과 마스크 경계 문턱 차이가 가능한 원인이지만, 원인을 따로 분리한 시험은 하지 않았다.
사전 기준대로 픽셀/좌표 완전 일치는 아니라고 기록하며 허용 오차를 사후에 추가하지 않는다.
24개 후보 중 하나를 고르는 판단, 다리 뒤 연결의 정답, Qwen 생성 개선은 검증하지 않았다.
공유 메모리 피크와 GPU 장치 전체 피크는 미측정. torch 메모리는 GPU 단일 프로세스 측정이다.

## 실행 명령
Windows에서 기존 운영 환경:
D:/genai-cache/venv/Scripts/python.exe -B <이 폴더>/gpu_probe.py --cache-dir D:/genai-cache/huggingface

기존 gpu_run이 있으면 덮어쓰지 않고 중단한다. 추가 GPU 실행은 이번 승인에 포함되지 않는다.
CPU 기준은 저장된 마스크이며 CPU 모델을 다시 실행하지 않았다.
