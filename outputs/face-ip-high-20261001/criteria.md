# 하이앵글 얼굴 참조 일정·강도 분리 — 사전 등록 (Codex 검토용)

## 질문
완성 프롬프트(high-decomp L4)를 고정했을 때, 얼굴 참조를 더하면 동일성은 오르지만(0 → 11/16) 붕괴가 1 → 4/16 으로 늘었다(L5: 0~10단계 0.5 → 11단계 0.9).
얼굴 참조의 일정·강도만 바꿔 동일성을 지키면서 붕괴를 늘리지 않는 설정이 있는가?

## 고정
high-decomp L4 와 같은 프롬프트·부정(성별 계약 방식)·하이앵글 골격(세기 1.2, 0~10단계)·seed 209210301~308·캐릭터 2명(ordinary 여성, raccoon 남성).

## 조건 (얼굴 IP 만 다름)
- A0 (재사용 high-decomp L4): 얼굴 IP 0.
- A1 (재사용 high-decomp L5): 0~10단계 0.5 → 11단계부터 0.9 (현재 조건부 일정).
- B: 0~10단계 0.0 → 11단계부터 0.9 (기본 일정, 초기 IP 없음).
- C: 0~10단계 0.0 → 11단계부터 0.7 (강도 낮춤).
- D: 0~13단계 0.0 → 14단계부터 0.9 (늦게 시작).

## 측정 (80장, 캐릭터별 섞은 블라인드 시트, 캐릭터 얼굴 원본·골격 함께)
실패 유형을 나눈다(Codex 검토 반영):
- SB 몸 구성 실패: 팔다리 뒤엉킴·몸 연결 이상·사람 겹침/뒤 실루엣·뒤집힘·반투명 덩어리 팔다리.
- SF 얼굴 없는 형체: 얼굴·머리 자리가 무늬 없는 덩어리, 마네킹·로봇처럼 보임.
- SC 머리 잘림/화면 밖(구도 실패).
- 정수리·머리카락으로 얼굴이 가려지는 것은 원본 구도와 같아 실패로 세지 않는다.
그리고 NP 인체 비율, V1 자세(위에서 내려다본 서 있는 사람, 휴대폰), VI 캐릭터(예/부분/아니오).

## 판정 (조건별 16장)
- 합격: VI "예" >= A1 − 2, 그리고 SB + SF <= A0 + 1, 그리고 NP "예" >= A0 − 2.
