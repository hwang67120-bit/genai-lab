# 사용자 시나리오

이 문서는 캐릭터 기준 이미지를 등록한 사용자가 생성 후보의 유사성을 직접 판단하는 흐름을 정의합니다. 구현 전에 사용자 행동과 프로그램 책임을 먼저 확정하기 위한 문서입니다.

## 현재 확정된 입력

사용자가 직접 입력하는 값은 다음 두 가지입니다.

1. 캐릭터 기준 이미지 한 장
2. 화면 범위 한 가지: 전신, 상반신 또는 얼굴 중심

사용자가 작성하는 생성 문장, 의상 참조, 자세 참조와 배경 입력은 현재 시나리오에 포함하지 않습니다.

## 결과의 단계와 이름

- **캐릭터 기준 이미지(CharacterReference)**: 닮게 생성해야 할 원본 이미지입니다.
- **생성 후보(GenerationCandidate)**: 모델 실행은 끝났지만 사용자가 아직 승인하지 않은 이미지입니다.
- **사용자 승인 결과(UserApprovedResult)**: 사용자가 기준 이미지와 충분히 유사하다고 판단하여 통과시킨 이미지입니다.

모델 실행이 성공했다는 이유만으로 생성 후보를 최종 결과라고 부르지 않습니다.

## 기본 흐름

```text
캐릭터 기준 이미지 등록
        ↓
화면 범위 선택
        ↓
생성 후보 한 장 생성
        ↓
프로그램의 기술 검사
        ↓
사용자가 기준 이미지와 비교
   ┌────┴────┐
 통과       재생성
   ↓          ↓
승인 결과   새 시드로 다음 후보 생성
```

한 실행에서는 후보를 한 장씩 만들며 최대 3장까지만 시도합니다. 사용자가 중간 후보를 통과시키면 남은 후보는 생성하지 않습니다.

## 프로그램이 자동으로 검사하는 항목

프로그램은 사실 여부가 명확한 기술 항목만 검사합니다.

- 이미지 파일이 생성됐는가
- 선택한 화면 크기로 저장됐는가
- 모델 실행 오류가 발생하지 않았는가
- 사용한 모델, 시드와 설정이 기록됐는가

기술 검사를 통과해도 캐릭터 유사성이 확인된 것은 아닙니다.

## 사용자가 판단하는 항목

사용자는 기준 이미지와 생성 후보를 직접 비교하여 다음을 판단합니다.

- 같은 캐릭터로 받아들일 수 있는가
- 얼굴, 머리색, 눈과 주요 디자인 특징이 충분히 유지됐는가
- 색감과 전체 분위기가 기준 이미지와 유사한가
- 선택한 화면 범위에 맞게 생성됐는가
- 실제로 사용할 수 있는 품질인가

## 사용자 선택

### 통과

기준 이미지와 충분히 유사하면 생성 후보를 사용자 승인 결과로 변경하고 해당 실행의 생성을 종료합니다.

### 재생성

유사하지 않거나 사용할 수 없는 품질이면 현재 이미지를 승인하지 않고 새로운 시드로 다음 생성 후보를 만듭니다.

## 자동 유사도 판정을 사용하지 않는 이유

캐릭터 유사성은 얼굴, 의상, 색감과 분위기를 함께 보는 주관적인 판단입니다. 별도 판정 모델을 추가하면 실행 시간과 메모리 사용이 늘어나며 사용자의 실제 선호와 다른 점수를 낼 수 있습니다.

현재 MVP에서는 자동 유사도 모델을 사용하지 않습니다. 프로그램은 기술적 성공만 검사하고 최종 유사성은 사용자가 결정합니다.

## 실패 사례 기준

다음 결과는 모델 실행이 성공했더라도 사용자가 재생성을 선택할 수 있는 생성 후보입니다.

- 기준 캐릭터와 다른 인물처럼 보임
- 얼굴이나 주요 디자인 특징이 사라짐
- 전신을 선택했지만 머리 또는 발끝이 잘림
- 일부 신체 부위만 과도하게 확대됨
- 그림체나 색감이 기준 이미지와 크게 다름

## 현재 구현과의 차이

현재 GUI는 기준 이미지 등록, 화면 범위 선택과 이미지 한 장 생성까지만 지원합니다. 생성 후보를 화면에서 비교하는 기능과 통과·재생성 버튼은 아직 구현되지 않았습니다.

## 아직 결정하지 않는 항목

다음 내용은 이 시나리오의 유사성 판정 범위에 포함하지 않습니다.

- 재생성할 때 이전 후보를 보존하거나 삭제하는 방식
- 승인 결과를 사용자가 지정한 폴더에 저장하는 방식
- 자동 자세·관절 검사 도입 여부
- 의상과 자세 참조 입력 방식

## 확정 결론

프로그램은 이미지 생성의 기술적 성공만 검사합니다. 캐릭터 유사성은 사용자가 생성 후보를 보고 `통과` 또는 `재생성`으로 결정합니다.
