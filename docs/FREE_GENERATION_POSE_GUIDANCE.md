# 자유 생성 자세 유도 설계 — 지원 자세 목록 + 골격 그림 (초안 2026-10-15, 구현 승인 전)

## 결론부터

- 문제: 자유 생성은 글 지시만으로 자세를 정한다. 무작위 생성이라 지시가 약하면 **구조가 틀린 그림**(요청 23 N1-tail: 앉음·섬이 겹친 다리 3개)이 나오고, 결과를 볼 때마다 문장을 더하는 조정이 끝없이 늘어난다(요청 20~24). 글 한 줄을 더해도 결과가 거의 안 바뀐 사례도 있다(요청 24).
- 방향(사용자 2026-10-15 "권고대로"): "자유" = **지원 자세 목록 안에서 사용자가 고르고 섞는 것**. 자세마다 **검증된 골격 그림**을 Qwen에 함께 줘서 구조를 그림으로 정하고, 결과 관절을 그 골격과 비교한다. 목록 밖 자세는 시작 전 "지원 범위 밖, 결과 보장 없음" 경고.
- 위험: 10월 초 Qwen 자세 편집(골격 그림 입력)은 자세가 불안정했다(사용자 판단 2026-10-04, D-077로 제외). 그래서 구현 전에 **작은 GPU 시험(요청 25 초안)**으로 골격 유도가 다리 개수·자세 일치를 실제로 낫게 하는지 먼저 본다.

## 1. 지원 자세 목록 v1

지금 코드의 고정 자세 8개(`free_generation.POSES`)를 출발점으로 한다: 한쪽 다리에 체중·손 허리, 걸어오기, 팔짱, 뒷짐·고개 기울임, 3/4 시점 손 흔들기, 스툴에 앉기, 한쪽 무릎 꿇기, 어깨 너머 보기.

- 사용자 요청 문장은 목록의 자세로 **분류**한다(낱말 규칙: sitting/앉/stool → 앉기, walking/걷 → 걷기 등). 분류가 안 되면 경고 후 글 지시만으로 진행(보장 없음)하거나 사용자가 목록에서 고른다.
- 배경·표정·시점 같은 자세 밖의 연출은 지금처럼 글로 전달한다.

## 2. 골격 그림

- 자세마다 기준 골격 하나(관절 좌표 18개, 코드에 상수로)를 둔다. 외부 다운로드 없이 코드로 그린다. 기존 `onepass_pose.prepare_qwen_control`의 크기·색 규칙을 재사용한다.
- **캐릭터 비율에 맞춤**: 기준 이미지의 관절(`detect_joints`, 이미 기준 분석에서 씀)로 어깨 폭·팔 길이·다리 길이를 재고, 기준 골격의 뼈 길이를 그 비율로 바꾼다(자세의 각도는 유지). 체형 동일성(어깨 처짐 포함) 원칙과 같은 방향.
- 기준 관절을 못 찾으면(가림·분할 실패) 표준 비율 골격 + 경고.

## 3. Qwen 입력과 검증

- image 1 기준 그림, image 2 머리 참조, **image 3 골격 그림**. 지시문에 "follow the pose skeleton in image 3" 한 문장.
- 작업 프로세스가 image 3이 코드의 골격 목록에서 만든 그림인지 다시 계산해 대조한다(머리 참조 검증과 같은 방식, 외부 그림 주입 방지).
- 메모리: 그림 하나가 늘어 text encode reserved가 오를 수 있다(지금 최고 6.36GiB, 상한 6.5GiB). 시험에서 먼저 잰다.

## 4. 결과 검사

- 결과 관절과 골격의 팔·다리 각도 차이 → 크면 `needs_review`("자세 다름"). 재시도 근거로 쓸지는 시험 뒤 결정.
- 다리·팔 개수 이상은 관절 검출이 한 사람분만 내놓아 여전히 자동으로 못 잡는다(요청 23). 사람 확인 문구 유지. 골격 유도는 '검출'이 아니라 '발생 감소'를 노린다.

## 5. 먼저 할 GPU 시험(요청 25 초안, Codex, 실행 승인 전)

| 줄 | 기준 | 자세 | 비교 |
|---|---|---|---|
| 1 | N1 원본 | 스툴에 앉기 + 골격 | 요청 21 N1-2(글만, 정상)·요청 23 N1-tail(글만, 다리 3개) |
| 2 | N2 원본 | 한쪽 무릎 꿇기 + 골격 | 같은 요청 글만(같은 seed) |
| 3 | K 원본 | 걸어오기 + 골격 | 같은 요청 글만(같은 seed) |

- 줄마다 골격 있음/없음 두 장(같은 seed) → 6장, 약 3.5시간. 이 시험에 필요한 코드(골격 목록·비율 맞춤·image 3 전달·검증)는 시험 승인 뒤 구현한다.
- 판정: 다리·팔 개수, 자세 일치, 캐릭터·의상 유지, 심한 이상. 골격 쪽이 구조 이상이 적고 동일성이 떨어지지 않으면 채택.

## 6. 완료 기준과의 관계

자유 생성 1차 완료 기준(제안: 품질 통과 70%, 같은 실패 반복 없음, 처음 보는 캐릭터 포함, 개선 최대 2번, 호환성 문서·거부 코드·출력 형식)을 "지원 자세 목록 기준"으로 잰다. 목록 밖 요청은 완료 판정 대상이 아니다.

## 하지 않는 것

- 자세 GUI(골격을 사용자가 직접 그리거나 고르는 화면) — 사용자 승인 전 제안·구현하지 않는다(2026-10-04 결정).
- 외부 골격 모델 다운로드, LLM 자세 해석, 학습.
