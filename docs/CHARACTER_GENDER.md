# 캐릭터 성별 사용자 지정

의상 디자인 참조 생성 설정에 지정 안 함 / 남성 / 여성 선택을 추가했다.
처음 여는 기준 이미지는 미선택 상태이며 선택 전 진행을 차단한다.
승인한 선택은 기준 이미지 파일별로 저장·복원한다. 지정 안 함도 명시적으로 선택해야 한다.
외형을 분석해 이 값을 자동으로 바꾸지 않는다.

- 남성: 실행 Positive의 첫 태그로 1boy 전달.
- 여성: 실행 Positive의 첫 태그로 1girl 전달.
- 지정 안 함: 기존 캐릭터 태그 승인 동작 유지. 중성/무성이라는 뜻이 아니다.
- 지정 시 분석기의 성별/인원 태그를 제거하고 사용자 선택 하나로 대체한다.
  태그 검토 화면에서도 해당 분석 태그는 선택할 수 없다.
- androgynous, 헤어, 눈, 체형, 의상 등 외형 태그는 성별을 이유로 제거하지 않는다.
  근육, 수염 같은 고정관념 기반 외형 태그를 자동 추가하지 않는다.
  단, 의상 출처에서 나온 체형 태그는 제외한다. 기준 캐릭터의 승인 체형 태그와 구분한다.
- 사용자 지정 남성은 Negative 첫 태그에 1girl, 여성은 1boy를 배치한다.
  이는 생성 유도 조건이며 결과 성별을 보장하지 않는다. 지정 안 함에서는 추가하지 않는다.
- Negative가 명시한 사용자 성별 자체를 금지하는 경우 해당 단독 태그를 제거한다.
- 지정값과 제거 항목은 실행 로그와 후보 JSON에 기록한다.
- 후보 비교 화면에 사용자 지정 성별을 표시한다.
- 의상 참조 강도, 배경, 포즈, 선화 활성 여부는 변경하지 않는다.

태그 필터는 명시적인 성별 태그를 대상으로 한다. 임의의 자연어 문장 전체를
이해하거나 성별을 생성 결과에 강제 고정하는 기능이 아니다. 최종 사용자 승인은 유지한다.
이번 검증은 UI·프롬프트·실제 생성 함수 전달 인자의 테스트이며 GPU 이미지 품질 시험은 아니다.

근거: [Animagine XL 3.1 Tag Ordering](https://huggingface.co/cagliostrolab/animagine-xl-3.1#usage-guidelines)
제작자는 학습 형식에 맞춰 1girl/1boy로 시작하는 태그 형식을 안내한다.
이 권장은 성별 재현의 정확도나 픽셀 보존을 보장하지 않는다.

## 의상 출처 격리와 후보별 제한 (2026-09-08)

의상 태그는 쉼표 분리와 정규화를 먼저 수행한 뒤 성별/체형 태그를 제외한다.
치마, 하이힐, 정장은 성별을 의미하는 태그로 취급하지 않는다.
실행 전 승인과 실제 생성은 같은 프롬프트 조립 함수를 사용한다.
제외 항목, 성별 Negative, garment_visual_gender_isolated=false를 후보 기록에 남긴다.
현재 IP-Adapter 이미지 임베딩 안의 체형 성분을 제거한 것은 아니다.
참조 이미지 전체의 성별 영향을 완전히 차단했다고 표시해서는 안 된다.

generation_timeout_seconds는 이제 후보별 제한이다. 기본값은 각각 1800초다.
공통 임베딩 준비에는 preparation_timeout_seconds를 별도로 사용한다.
이전 후보와 유사도 계산은 다음 후보의 생성 예산을 소모하지 않는다.
중단/시간 제한은 추론 스텝 및 함수 반환 경계에서 확인하며, 실행 중인 CUDA 호출을
강제 종료하지는 않는다. 완료된 이전 후보는 그대로 보존한다.

근거 문서:

- [Python perf_counter](https://docs.python.org/3/library/time.html#time.perf_counter): 경과 시간 측정.
- [Diffusers IP-Adapter](https://huggingface.co/docs/diffusers/v0.38.0/en/using-diffusers/ip_adapter): 이미지 특징을 별도 조건으로 전달하는 구조. 이미지 내부 성별 분리 기능을 의미하지 않는다.
