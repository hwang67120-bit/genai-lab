# 참조 그림 넣는 곳

참조 그림을 `style.png`라는 이름으로 이 폴더에 넣습니다.

- 권장 형식: PNG 또는 JPG
- 권장 크기: 가로·세로 512픽셀 이상
- 한 장 참조 시험이 끝나기 전에는 여러 파일을 넣지 않습니다.
- 참조 그림의 장면을 복사하는 것이 아니라 색감·선화·명암·질감이 전달되는지 확인합니다.


## 사용자 지정 제외 자료

저장소 루트 `reference-exclusions.json`에 등록된 파일명 또는 SHA-256과 일치하는 자료는 테스트·갤러리·생성 입력에서 제외합니다. 원본과 크롭·썸네일·접촉 시트 등 파생 이미지를 Git에 추가하거나 외부 게시하지 않습니다. 이름이 바뀌어도 같은 SHA-256이면 제외 대상입니다. `.gitignore`를 우회하는 `git add -f`도 금지합니다.

이 목록은 입력 선정 및 게시 규칙입니다. 기존 생성기 전체에 자동 차단 로직을 추가했다는 의미는 아닙니다. 새 진단 하니스는 이 목록을 먼저 반영해야 합니다.
