# GPU 시험 요청 20 초안 — 같은 기준·의상의 자유 생성 첫 측정

초안 작성 완료이며 실행은 아직 승인되지 않았다. 이번 구현 작업에서는 GPU를 실행하지 않는다.

## 비교 목적

승인된 의상 편집본을 기준으로 같은 캐릭터와 의상을 유지하면서 자세·구도·배경을 새로 만들 수 있는지 확인한다. 기존 의상 편집의 미해결 실패는 별도이며 이 시험으로 해결됐다고 보고하지 않는다. 원본 캔버스 시험은 별도 대조군으로만 분류한다.

## 입력과 여섯 실행

사용자가 승인·저장한 성인 캐릭터 편집본 세 장(A/B/C)과 그 이미지 SHA가 일치하는 `.review.json`을 먼저 확정한다. 현재 미커밋 `approved-bases`의 SDXL 과거 자료를 Qwen 의상 편집 승인본으로 자동 채택하지 않는다. 적어도 꼬리/귀 또는 날개가 있는 두 캐릭터와 부위가 없는 한 캐릭터를 권한다. 자료가 부족하면 시작을 보류하며 승인 기록을 만들어 채우지 않는다.

| 줄 | 기준 | 연출 요청 | 비교 질문 |
|---|---|---|---|
| 1 | A 승인 편집본 | 빈 요청 → selection_seed 42의 코드 고정 자세 | 의상·부위·특징 유지, 선택 자세 반영 |
| 2 | A 승인 편집본 | sitting on a simple stool, hands on knees, three-quarter view | 앉기와 시점 변화에도 연결·손·의상 유지 |
| 3 | B 승인 편집본 | 빈 요청 → 같은 선택 규칙 | 다른 특징·부위에서도 공통 경로 유지 |
| 4 | B 승인 편집본 | walking in a snowy street | 배경 허용과 캐릭터·의상 유지 |
| 5 | C 승인 편집본 | 빈 요청 → 같은 선택 규칙 | 없는 귀·꼬리·날개 추가 여부 |
| 6 | C 승인 편집본 | standing with eyes closed, head tilted slightly | 표정 연출을 외형 변경으로 오거부하지 않고 반영 |

캐릭터/의상 차이와 무작위/지정 연출을 비교한다. 머리 크롭 유무의 인과 A/B가 아니며, 효과 원인을 크롭 하나로 단정하지 않는다. 원본 대조군이 필요하면 사용자 결정 후 별도 목록으로 추가하되 위 여섯 건을 대체하거나 의상 교체 통과율에 섞지 않는다.

## 고정 조건과 사전 검사

- 공통 `run_free_generation`, Qwen-Image-Edit-2511, 기존 로컬 모델/워커/설정. 40단계, CFG 4.0, guidance 1.0, group_block1. 설치·다운로드·RAG·추가 학습·머리 합성 없음.
- 기준 768×1024 캔버스와 같은 기준에서 파생한 머리 크롭만 입력. 모델 출력 896×1184. 이미지·프롬프트·설정·모델 명세·코드·계약·특징표·기준/승인 기록 SHA를 실행 전후 잠근다.
- 사용자 확정 성별·부위·특징표 고정. 의상은 기준 그대로. 배경 요청 없는 줄은 흰 배경. selection_seed 42, 생성 seed 42; 제품 자동 재시도만 43 한 번 허용하고 동일 프롬프트·연출·참조를 유지한다.
- GUI/공통 함수 CPU 검사 통과 기록 확인. 모든 실제 요청을 잠근 조건과 대조. 입력 계약/메모리/Qwen 실패는 중단하고 자동 수정·재실행하지 않는다.
- GPU 작업은 순차 실행. 기준 분할 프로세스 종료 → Qwen 종료 → 결과 자체 분할. 원본 마스크·원본 좌표를 결과에 대지 않는다.

## 판정 기준과 기록

실행 completed와 사용자 품질 승인은 따로 집계한다. 합성률은 사용하지 않는다(합성 없음). 첫 측정이므로 새로운 임의 목표 통과율을 만들지 않는다.

각 줄에서 기준 | 실제 머리 참조 | seed42 raw | 재시도 raw(있으면)를 보여 주고 결과별로 같은 캐릭터 yes/no, 의상 same/partial/different, request_followed yes/partial/no, 부위 kept/changed/missing/added, 심한 이상 none/present+내용을 사람이 기록한다. 자동 관찰은 근거이며 자동 통과를 최종 품질 통과로 승격하지 않는다. 모든 핵심 항목이 유지/반영되고 심한 이상이 없다고 사용자가 명시적으로 승인한 줄만 자유 생성 품질 승인으로 집계한다. 미검토·확인 불가는 통과로 세지 않는다.

꼬리·날개·귀의 실제 개수/색/형태/엉덩이 연결·끊김/추가/소실, 기존 기준 의상과 조끼·셔츠·벨트·바지·구두 세부, 머리 중복·위치, 팔/손 가림과 미검출 오판을 실제 raw에서 확인한다. 분할 연결 요소 수는 실제 개수가 아니다. 요청의 배경·표정·자세 반영은 사람이 검토한다.

`trace.json`, `inputs/conditions.json`, 모든 `qwen[-2]/request.json`, 실제 `model_inputs` 이미지·문장, run.json 최고 reserved·시간, 결과 분할/특징 관찰, 사용자 judgement.json을 보존한다. 주체·대상 시도/이미지 SHA·근거를 연결한다. 입력/모델/코드/설정/계약 SHA 불일치, 메모리 중단, 미검토는 숨기지 않는다.

## 예상 시간·메모리와 종료

과거 Qwen 의상 시험을 근거로 한 예산 추정이며 자유 생성 GPU 실측이 아니다. 한 시도 약 30분 + 분석/분할 시간. 여섯 줄 약 3~4시간, 전부 한 번 재시도하면 약 6~8시간을 예상한다. Qwen reserved 상한 6.5GiB·VAE 타일·lm_head CPU 정책을 유지한다. 기준/결과 분할은 별도 프로세스로 메모리 측정값을 함께 기록하고 Qwen 수치에 합치지 않는다. 공유 GPU 작업과 겹치면 시작을 보류한다.

여섯 줄과 허용된 재시도 완료 후 종료. 계약 불일치·메모리 초과·모델 실패면 즉시 실패 보고하고 자동 재실행하지 않는다. 분석 실패는 확인 불가로 표시하고 결과 검토로 넘긴다. 시험 도중 코드·조건 조정이나 추가 seed를 섞지 않는다.

## 결과별 다음 결정

- 같은 캐릭터·의상·요청이 유지되고 새 심한 이상 없음: 사용자 승인 사례를 보존하고 다음 배치 범위를 결정한다. 편집 단계 성공으로 환산하지 않는다.
- 특징/부위 변화 반복: 실패 근거의 입력 사실→실제 조건→출력 관찰→판정을 검토한 뒤 공통 조건 또는 참조 방식 수정 설계를 제안한다. 캐릭터별 예외·학습을 바로 추가하지 않는다.
- 의상 세부 변화 반복: 자유 생성 의상 보존 문제로 분리해 해결 설계를 제안한다. 기준을 partial로 임의 완화하지 않는다.
- 요청 미반영: 같은 입력의 연출 조건 설계를 먼저 검토한다. 배경만 성공하면 자세·구도 성공으로 세지 않는다.
- 분할/관절 확인 불가: 분석 개선과 추가 생성의 필요를 분리한다. 저장된 raw를 먼저 보고 새 GPU 생성 여부는 사용자가 결정한다.
