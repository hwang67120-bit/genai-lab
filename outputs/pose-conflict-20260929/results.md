## 시험 1: 주머니 없는 원피스 + 주머니 자세 → PK1 + PK2 (규칙 채택 근거)
| | PA (hands_in_pockets 유지) | PB (제거) |
|---|---|---|
| 엄격 의상 GD (태거) | 6/12 | 9/12 |
| 육안 의상 "예" | 5/12 | 7/12 |
| 주머니 있는 옷으로 바뀜/겉옷 추가 (VP) | 5/12 (셔츠 원피스 1, 튜닉 1, 재킷·후드 3) | 0/12 |
| 원피스에 없던 주머니가 생김 (note) | 5/12 | 0 |
| 손이 주머니에 들어감 | 10/12 | 0 |
| 자세 "예" | 10/12 | 8/12 |
| 형체 붕괴 | 1 (R6 무지개) | 2 (R6 무지개, O5 얼굴 없는 뒤통수) |

- PK1: 6 <= 9 − 3 성립. 주머니 태그는 주머니를 "만든다": 절반은 원피스에 주머니를 그려 넣고, 절반은 주머니 있는 옷(재킷·후드·셔츠)으로 바꾼다.
- PK2: 자세 8 >= 10 − 2, 붕괴 2 <= 1 + 1 성립 (경계값). 빼면 손은 옆·뒤·허벅지로 가고 몸 자세는 대체로 유지.
- 결론: "의상에 주머니가 없으면 hands_in_pockets 를 뺀다" 규칙의 근거가 된다. 단, 두 조건 모두 경계값이고 표본 12라 강한 근거는 아니다.
- 태거 한계: 슬립 원피스(PB O6)를 dress 0.08 로 놓침, 레오타드처럼 보이는 결과(PB R5)는 노출 B 로 잡힘.

## 시험 2: 총 태그 제거 → GN2 + GN3 (소품 태그 필요, 빼도 총이 나온다)
| | GA (총 태그 전부) | GB (aiming 만) |
|---|---|---|
| 형체 붕괴 | 1/12 | 6/12 (뒤집힌 몸 2, 흐린 몸 1, 머리카락 폭발 1, 작은 인물 2) |
| 자세 "예" | 6/12 | 3/12 |
| 총이 있는 결과 (육안) | 12/12 | 5/12 (+1 판단 어려움) |
| 빈손 조준 (손가락 총) | – | 1/12 |
| 엄격 의상 G (태거) | 11/12 | 9/12 |
| 노출 A·B 적중 | 1 (C4 재사용 O1 underwear) | 3 (모두 붕괴 결과: swimsuit, panties×2) |

- GN1 불성립. GN2 성립: 붕괴 6 >= 1 + 3, 자세 3 <= 6 − 3. GN3 성립: 태그를 빼도 5/12 에서 총이 나온다 (aiming·골격이 총을 부름).
- 소품 태그는 팔 모양을 설명하는 구조 정보 역할도 한다. 빼면 모델이 "앞으로 뻗은 팔"을 해석하지 못해 몸을 뒤집거나 흐리게 만든다.
- 결론: 총 자세에서 소품만 지우는 방식은 쓸 수 없다. 소품을 원하지 않으면 자세 이미지를 바꾸는 쪽이 맞다.

## 종합
- 손과 의상의 관계(주머니)는 의상 조건에 따라 빼도 된다: 몸 자세는 골격이 잡아 준다.
- 소품을 쥐는 자세는 소품 태그가 자세 안정에 필요하다: 빼면 붕괴가 크게 는다.
- 노출 게이트 v4 는 붕괴 결과의 노출(nude·panties·swimsuit)을 잡았다 (A·B 적중 6장 중 4장이 붕괴 결과; 나머지는 레오타드처럼 보인 PB R5, C4 재사용 O1 underwear).
- 태그 칩 분류 후보: 자세·구도 = 유지, 손-의상 관계 = 의상 조건부, 쥐는 소품 = 유지(끄면 경고 또는 다른 자세 권유).
