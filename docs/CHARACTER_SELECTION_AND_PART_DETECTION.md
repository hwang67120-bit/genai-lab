# 성별 선택 유지와 귀·꼬리 자동 검출

## 성별 선택

- 기준 이미지의 정규화된 절대 경로를 해시한 키로 QSettings에 사용자 선택을 저장한다.
- 같은 이미지 파일은 앱을 다시 열어도 복원한다. 다른 이미지에 선택을 자동 전파하지 않는다.
- 최초 상태는 미선택이다. 남성/여성/명시적으로 지정하지 않음 중 하나를 선택해야 진행한다.
- 취소한 설정은 저장하지 않는다. 승인값은 설정 승인 로그와 실제 생성 프롬프트 기록에서 대조한다.
- 성별 프롬프트는 생성 조건이며, 결과 외형을 강제로 보장하지 않는다.

## 의상 참조 ON

A/B 체크박스와 실행 분기를 제거했다. 후보마다 동일한 양수 의상 참조 강도를 사용한다.
시드는 후보 번호만큼 증가한다. 오래된 garment_ab_test 값이 남아도 OFF 후보를 만들지 않는다.
기존 후보별 타이머와 완료 후보 보존은 유지한다.

## 자동 검출과 생성 참조의 차이

기존 clothing_preparation의 Grounding DINO, clothing_mask_extraction의 SAM2 모델 캐시를
재사용한다. Transformers SAM2 영상 설정을 이미지 설정으로 변환하는 기존 로더도 재사용한다.
CPU에서 실행하며 모델 다운로드나 추가 라이브러리 설치는 자동 수행하지 않는다.
캐시/의존성이 없으면 오류를 표시한다. 원본 검출은 reference_analysis.part_detection.enabled로 설정한다.

귀와 꼬리를 각각 검색하고 SAM2로 마스크를 만든다. 종, 털색, 꼬리 수를 추정 태그로 확정하지 않는다.
검출 점수와 마스크 품질 점수는 서로 다르며 임계값은 품질 검증을 거치지 않은 초기값이다.
미검출은 부위 부재가 아니다. 잘못된 좌표, 과다 검출, 잘못된 마스크 크기는 오류다.

기본 모드는 원본 검출/미리보기 전용이다. 원본 마스크, 원본 RGB 크롭, 점수와 상태를
임시 genai-parts-* 폴더에 저장하고 입력 검토 화면과 후보 기록에 경로를 남긴다.
생성 위치가 확정되지 않았으므로 귀·꼬리 이미지를 IP-Adapter에 전달하지 않는다.
화면에는 검출 완료/생성 위치 미확정/참조 미전달을 명시한다.
추가 부위가 0개라는 로그는 생성 참조 개수이고, 원본 검출 개수는 별도로 기록한다.

기존 part_analyzer 주입 경로는 유지한다. 생성 위치 판단기를 구현하여 target_region을
제공하면 prepare_extra_references가 얼굴·의상과의 충돌, 빈 영역, 좌표 크기를 검증한 뒤 연결한다.
원본 마스크를 생성 좌표로 무조건 복사하지 않는다. 위치·가려짐 자동 판단은 아직 미구현이다.

시간 제한은 모델 호출 전후에 검사한다. 진행 중인 CPU 추론을 즉시 강제 종료하는 기능은 아니다.
사람 귀·동물 귀·꼬리·헤어 장식의 4개 독립 쿼리는 콜드 실행에서 120초를 넘을 수 있어 기본 제한을 300초로 둔다. 두 모델의 실제 검출 품질은 사용자 이미지에서 계속 측정해야 한다.
검토 화면은 스크롤 가능하고 승인/취소 버튼은 아래에 고정되어 있다.

## 검증 범위

테스트는 선택 저장/복원, 미선택 차단, ON 후보 조건, 검출기 대역의 마스크 계약,
미검출/오류/취소/시간 초과, 미리보기와 생성 참조 분리를 확인한다.
실제 DINO/SAM2 추론 및 GPU 생성 품질을 검증한 결과가 아니다.

## 근거

- [Qt QSettings](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QSettings.html): 설정 저장/복원.
- [Grounding DINO](https://huggingface.co/docs/transformers/model_doc/grounding-dino): 텍스트 기반 위치 검출.
- [Transformers SAM2](https://huggingface.co/docs/transformers/model_doc/sam2): 박스 기반 분할과 마스크 후처리.
- [IP-Adapter](https://huggingface.co/docs/diffusers/v0.38.0/en/using-diffusers/ip_adapter): 이미지 참조와 출력 영역 마스크.
