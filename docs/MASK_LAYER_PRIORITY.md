# 의상 제거: 자동 후보와 사용자 추가·제외

2026-09-06 구현. 기준 이미지 생성, DWPose, 신체 복원 모델은 변경하지 않는다.
꼬리·동물 귀는 별도 자동 보호 클래스로 추가하지 않는다.

## 바뀐 흐름

1. 기존 기준 캐릭터 마스크 창에서 '자동 의상 후보를 기본으로 사용'이 기본 선택된다.
2. 전체 의상을 수동으로 선택하지 않고 다음 분석/검토로 진행할 수 있다.
   선택 창에서 자동 마스크가 즉시 계산되는 것은 아니다. 기존 외부 분석 작업을
   실행한 다음 Human-Agnostic 검토 화면에서 실제 결과를 확인한다.
3. 필요한 경우 SAM2 후보 승인으로 의상 영역을 추가하거나 제거에서 제외한다.
   사각형 자체가 아니라 실제 승인한 SAM2 픽셀만 반영한다.
4. 같은 역할의 선택은 픽셀별 maximum으로 누적한다. 추가/제외가 겹치면
   마지막 작업이 반대쪽 레이어에서 해당 픽셀을 해제한다.
   소프트 알파는 누적 중 유지하고 승인·실행 계약에서는 128 기준으로 이진화한다.
5. 사용자가 별도로 지정한 보호와 추가가 충돌하면 기존 선택 검토에서 해소한다.
6. 자동 의상 후보 + 추가/제외 + 보호로 합성한 결과를 검토한 뒤 실행한다.
   추가·제외 선택 초기화 버튼은 명시적 보호를 지우지 않는다.

## 합성 예시

아래 배열은 크기가 같은 Boolean 배열이다.

```python
fixed_keep = face_and_hair | user_keep | user_exclude
effective_protection = fixed_keep | (auto_protection & ~user_add)
requested = auto_clothing | user_add
final_mask = requested & foreground & ~effective_protection
```

자동 기본을 끄면 requested에는 user_add만 사용한다.
얼굴·머리카락은 고정 보호이며 다른 자동 보호와 구분한다.
따라서 수동 추가가 얼굴·머리까지 무조건 지우지는 않는다.
후속 닫기 보정, 중립화, preflight, 신체 초기화는 합성 후의
effective_protection을 그대로 이어받아, 해제한 자동 보호를 다시 적용하지 않는다.
자동 보정도 user_exclude 영역을 다시 추가하지 않는다.

기존 AutoMasker/SCHP/DensePose 결과를 재사용한다. 레이어 모드에서 전신 의상
후보를 만들고 SCHP의 의상·신발·양말·장갑·스카프 클래스도 후보에 합친다.
공식 모델의 기본 신발 보존 규칙과 '기존 의상 전체 교체' 목적을 구분하기 위함이다.
새 모델이나 추가 추론 호출을 넣지는 않았다.

## 검토 화면과 로그

Human-Agnostic 검토에 원본 위 레이어 표시를 추가했다.

- 빨강: 합성된 제거 후보
- 파랑: 얼굴·머리·명시적 보호/제외
- 초록: 사용자 추가로 다른 자동 보호를 해제한 위치
- 노랑: 사용자 추가와 얼굴·머리/명시적 보호의 충돌
- 자홍: 사용자 추가 중 캐릭터 외곽 밖 판정

각 영역의 개별 흑백 마스크도 표시한다. 색상 오버레이는 진단용이며 생성 입력이 아니다.
outputs/debug_removal JSONL의 mask_layer_priority에 각 레이어 픽셀 수·해시,
충돌/자동 보호 수정/외곽 제외 수치를 남긴다.

## 남은 한계

- 얼굴·머리로 잘못 분류된 옷깃은 여전히 제외된다. 노랑 표시를 통해
  분류 오류인지 확인해야 하며 이번 변경이 그 오인식을 교정하는 것은 아니다.
- 외곽에서 누락된 의상도 이번 변경만으로 복구되지 않는다.
- SAM2 후보 자체가 잘못됐을 때는 추가/제외 선택을 다시 확인해야 한다.
- 자동 의상 후보가 정확하다는 보장이 없으므로 기존 결과 승인은 유지한다.
- 몸 복원 품질, 얼굴 관절 오차, 생성 속도/최소 사양은 이번 수정의 검증 범위가 아니다.
- 기존 비레이어 API는 하위 호환을 유지하며 GUI의 새 승인 경로에서 레이어 모드를 사용한다.

## 근거

검증: 2026-09-06 Windows 런타임의 관련 18개 모듈에서 150 passed (20.62초).
추가 선택 누적, 사용자 제외, 얼굴·머리 보호, 자동 보호 수정, 후속 중립화 전달,
자동 후보만으로 승인 가능한 GUI, 기존 마스크·가드레일 회귀를 확인했다.
외부 분석은 테스트 대역을 사용했으며 실제 GPU 추론/시각적 품질은 검증하지 않았다.
코드는 Linux 공유 경로에서 수정했고 git diff --check를 통과했다.

- [NumPy maximum](https://numpy.org/doc/stable/reference/generated/numpy.maximum.html):
  픽셀별 최댓값을 이용한 마스크 누적.
- [NumPy logical_or](https://numpy.org/doc/stable/reference/generated/numpy.logical_or.html):
  Boolean 영역의 합집합.
- [CatVTON 공식 자동 마스크 구현](https://github.com/Zheng-Chong/CatVTON/blob/main/model/cloth_masker.py):
  의상 분류와 보호 우선순위의 원래 동작.

라이브러리 문서는 연산의 근거이며 캐릭터 분류 정확도를 보장하지 않는다.
