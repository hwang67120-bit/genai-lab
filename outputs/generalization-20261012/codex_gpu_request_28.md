# GPU 시험 요청 28 — 생성 쪽 원인 가설 2개 한 요인 확인 (초안 2026-10-19)

요청 27 분석(D-137 앞 원인 분석)에서 남은 생성 쪽 가설 두 개를 **한 요인만 바꿔** 확인한다. 품질 평가 세트가 아니라 원인 확인이다. 상태: **초안 — 사용자 승인 전**. 실행: **Codex**. 선행 구현: Claude(아래 '선행 구현', 기본값은 지금과 같고 시험에서만 켠다).

## 가설

- **A. 색 이름 낱말이 실제 색을 대표색 쪽으로 끈다.** 근거: F5 `dark skin` → 지나치게 어두움(D-134), M6 `blue hair` → 옅은 청회색이 청록·고채도(색조 281° → 255~270°, 채도 21 → 23~36), M3 `blonde hair` → 분홍빛 금발이 노란 금발(색조 32° → 70°). 머리 참조 입력(VL2)에는 원래 색이 그대로 보인다 — "입력에는 있고 출력에서 달라짐". 낱말만 뺀 비교는 없었다.
- **B. 지시문 안의 부정형 "no … tail … do not add any"가 오히려 꼬리를 부른다.** 근거: 꼬리 없는 M2·K 해변 재시도(seed 43)에서 요청 26·27 모두 꼬리가 생김. 지금 부정 지시문 칸은 비어 있다(`negative " "`, true CFG 4.0) — 모델이 실제로 지원하는 제어 수단인데 쓰지 않고 있다.

## 고정할 것(요청 27과 같음)

기준 그림·특징표(`eval-set-26/proposed-inputs.json`)·머리 참조·장면 문장·seed·설정·GGUF·40단계·true CFG 4.0·골격 유도 꺼짐. **제품 재시도는 끄고 줄마다 1장만**(같은 seed끼리 비교). 대조군은 요청 27의 같은 seed 결과를 쓰고, 재현성 확인으로 대조군 1장만 다시 만든다.

## 선행 구현(Claude, 승인 뒤 · GPU 전)

- 실험 선택지 두 개, **기본 꺼짐**, 켜면 trace·request에 기록:
  - `hair_color_words=False`: `features_sentence`에서 머리색 태그 낱말만 뺀다(`HAIR_PLACEMENT`·고유 형태 메모·검증은 그대로).
  - `absent_parts_as_negative=True`: 없는 부위 문장을 지시문에서 빼고 부정 지시문 칸에 넣는다. 작업 프로세스의 지시문 대조(`qwen_free_generation.py`의 negative `" "` 고정 검사)를 요청에 적힌 negative와 대조하도록 바꾼다.
- 제품 재시도 끄기는 실행기에서 한 시도만 부르는 방식으로(제품 코드 기본값 변경 없음).
- CPU 시험: 두 선택지를 켰을 때 실제 지시문 차이가 위 표의 문장뿐인지, 껐을 때 요청 27과 지시문이 바이트 단위로 같은지.

## 사전 검사(Codex)

- 줄마다 대조군(요청 27) 지시문과 새 지시문의 차이가 **표의 문장뿐**인지 문자 단위로 대조(그 밖의 차이가 있으면 시작하지 않고 보고). A0은 차이 0.
- 입력 SHA·설정·모델 SHA 잠금. 배치 중 Claude는 커밋하지 않고 상태 파일을 열지 않는다(수정 시각만).
- 모델 SHA 불일치·작업 프로세스 비정상 종료는 그 줄에서 멈추고 보고, 자동 재실행 금지. 메모리 검사는 하지 않는다(사용자 결정). 10/20 램 교체 뒤에 돌려도 된다.

## 기록과 판정

- 측정(자동, 같은 방법): 머리 영역 a·b 중앙값의 기준 대비 색조 차이·채도 차이, 피부 대비 이동 방향(D-137 `cast_test`), 위·가운데·끝 띠별 색 오차. 꼬리: 결과 태그·분할(믿기 어려움 — 참고만).
- 사람 판정(작은 묶음, 대조군과 나란히): A는 "머리색이 원본에 더 가까운 쪽(새/대조/같음)"과 다른 특징이 나빠졌는지, B는 "꼬리 있음/없음"과 다른 부위·의상 변화.
- A0 재현성: 대조군과 픽셀이 다르면 차이 크기를 기록하고, 이후 비교에서 그 정도 차이는 '같음'으로 본다.

## 종료 기준과 다음 결정

- **A 채택**: A1~A4 중 3쌍 이상에서 사람이 '새 쪽이 원본에 더 가까움' + 측정상 색조 차이가 대조군보다 10° 이상 줄거나 채도 오차가 절반 이하 + 다른 특징 악화 0 → 머리색 낱말을 지시문에서 빼는 것을 기본으로 제안(피부 낱말 D-136도 같은 원리로 재검토). **기각**: 2쌍 이하 → 가설 A 버림, 머리색은 D-137 자동 보정에 맡김.
- **B 채택**: B1·B2 모두 꼬리 없음 + B3·B4에 새 부위·의상 악화 없음 → 없는 부위는 부정 지시문으로 옮기는 것을 기본으로 제안. **기각**: B1·B2 중 하나라도 꼬리 → 가설 B 버림, 꼬리 추가는 사람 판정 + 지원 범위 경고로.
- 어느 쪽이든 결과는 요청 27의 판정·통과 줄 수를 바꾸지 않는다(평가 세트 재측정이 아님). 채택한 변경은 다음 평가 세트 측정에서 효과를 다시 잰다.
