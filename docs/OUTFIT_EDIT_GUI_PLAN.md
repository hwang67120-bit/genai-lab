# 원본 편집형 의상 교체 — GUI 연결 계획 (D-094)

> 기록 2026-10-12, Claude. 제품 계약(FLOW.md) 갱신 전의 작업 계획이다. 단계마다 CPU 테스트와 Codex GPU 확인을 거친다.

## 결론
- 사용자 결정(2026-10-12): 시험 11 통과 뒤 **"편집 이후 자유 생성"**으로 전환한다.
  - 자유 생성 범위: 자세 · 구도·시점 · 배경 · 문장으로 자유 요청.
  - 순서: **편집 단계 GUI 연결을 먼저** 하고, 그다음 자유 생성 시험을 한다.
- 편집 단계는 다음과 같다.
  1. 원본 캐릭터와 의상 그림을 Qwen-Image-Edit로 편집해 옷을 바꾼다.
  2. 머리(머리카락·얼굴·선택한 머리 장식)만 원본 픽셀로 붙인다.
  3. 정렬·형태 검사를 통과하지 못하면 붙이지 않는다.
  4. 결과 1장을 사용자가 확인한다.

## 단계
| 단계 | 내용 | 확인 |
|---|---|---|
| 1 | 공통 모듈 `genai_lab/outfit_edit.py`. 시험 실행기의 정렬·형태·합성·메모리 기록을 옮기고, 제품 지시문(`outfit_prompt`)을 추가한다. | CPU: 시험 08~11 저장 결과 판정 재현(9/9 동일) |
| 2 | Qwen 작업 프로세스에 `outfit_edit` 종류 추가(`genai_lab/qwen_outfit_edit.py`, `qwen_pose_worker.py`). lm_head CPU, VAE 타일, 6.5GiB 할당 상한, 단계별 메모리를 적용한다. 자세·꼬리 경로는 바꾸지 않는다. | CPU 완료 → GPU 요청 12 |
| 3 | `genai_lab/outfit_edit_pipeline.py`: 캔버스 준비 → See-through 분할(`outfit_edit_worker.py`, 별도 프로세스라 GUI 프로세스는 CUDA를 잡지 않음) → Qwen → CPU 정렬·검사·합성. GPU 확인 실행기 `scripts/outfit_edit_gpu_check.py`. | CPU 완료 → GPU 요청 12 |
| 4 | 작업실 연결 | CPU GUI 테스트 → 사용자 GUI 확인 |
| 5 | 자유 생성(편집 결과를 기준 이미지로): 자세·구도·배경·문장 | 별도 설계·시험 |

4단계 작업실 연결의 세부:
- 선택 체크 "원본 그림에서 옷만 바꾸기(약 30분)"를 둔다. 기본은 꺼짐이다.
- 그 아래 "머리 장식 유지" 체크를 둔다. 기본은 켜짐이다. 사용자가 시험 10에서 장식 유지 결과를 가장 동일성이 높다고 판정했다. 장식 삭제는 머리 모양이 바뀌는 문제가 남아 있다.
- 기존 입력 확인 → 편집 → 결과 1장 확인 → 승인·저장 흐름을 쓴다.

## 정해진 것
- 제품 지시문에는 의상 묘사를 쓰지 않는다. "그림 2의 옷을 모양·길이·색·세부까지 따르게"라고만 쓴다.
  - 시험 지시문의 "long dark brown coat"가 의상을 바꾼 정황이 있다(D-092).
  - 이 일반 지시문은 GPU에서 아직 확인하지 않았다. 2단계 GPU 확인에 포함한다.
- 머리 장식 선택은 머리 장식(headwear·earwear·eyewear)에만 적용한다. 무기 등 다른 소품은 항상 지운다.
- 메모리는 6.5GiB 상한을 유지한다. 시험 10~11에서 VAE 타일을 켜고 6.3GiB였다.
- 정렬·형태 검사 기준값은 D-093 그대로다. 캐릭터별로 바꾸지 않는다.

## 열린 문제
- 제품 계약 `FLOW.md`는 "픽셀 합성·마스크 병합"을 제외 항목으로 두고 있다. 편집 단계를 제품에 넣으려면 계약 갱신이 필요하다(사용자 승인 후).
- 자유 생성 범위는 이전 결정을 다시 연다.
  - 자세 변경: 10/9 범위 제외(D-077)
  - 배경: 단일 캐릭터·배경 없음
  - 범용 자유 문장: 배포 후 별도
- 장식 삭제는 머리 모양을 바꾼다(시험 11 W3). 형태 검사가 걸러 내지만, 결과가 없으면 사용자는 다시 시도해야 한다.
- 원본 자세·체형은 편집에서 유지되지 않는다. Qwen은 정면 선 자세와 마른 체형으로 그렸고, 머리 대비 키가 0~7% 늘었다. 사용자는 시험 11에서 "체형 같음"으로 판정했다.
- 한 장에 약 28~30분이 걸린다.
