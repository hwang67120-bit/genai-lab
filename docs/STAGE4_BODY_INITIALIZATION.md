# 4단계: 신체·배경 구분 초기 이미지

2026-09-05 구현 범위. 이는 생성 완료 이미지나 숨은 신체 정답이 아니라
기존 ControlNet Inpaint에 전달할 초기 조건이다. 실제 GPU 품질은 별도 확인한다.

## 입력과 처리

- 승인된 원본 캐릭터, 원본 DWPose 좌표·지도, 제거 마스크,
  승인 외곽(기존 외곽 확장 포함)과 보호 마스크를 재사용한다.
- 관절을 연결한 팔다리 캡슐과 몸통·골반 다각형으로 체형 후보를 만든다.
  폭 계수는 초기 휴리스틱이며 두꺼운 옷의 숨은 체형을 측정한 값이 아니다.
- 제거 마스크 내부를 피부, 불투명 기본복, 배경 영역으로 서로 겹치지 않게 분리한다.
  세 영역의 합은 기존 제거 마스크와 같다. 제거 마스크를 수축하거나 추가 모델을 로딩하지 않는다.
- 몸통·골반에는 단색 불투명 기본복 RGB (48, 72, 104)를 사용한다.
  피부는 기본복 밖의 팔다리·목 연결 영역에 초기화한다. 해부학적 세부 묘사를 요구하지 않는다.
- 승인 범위 밖과 보호 영역 픽셀은 원본 그대로 유지한다.

## 피부색 표본의 의미

눈과 코 관절로 볼 주변 후보를 잡고, 후보에서 우세한 색 군집의 중앙값을 추출한다.
고정 살색 임계값이나 생성 모델이 추측한 피부색은 사용하지 않는다.
손 후보는 얼굴색과 비교만 하고 혼합하지 않는다. 장갑이나 다른 조명 때문에 색이
다를 수 있다. 표본은 의미론적 피부 분할이 아니므로 눈, 홍조, 머리카락을 잡을 수 있다.
최소 표본이 없거나 필수 관절이 없으면 임의의 색/좌표로 진행하지 않고 이유를 표시한다.

배경은 승인 외곽 주변의 중앙값 색으로 초기화한다. 복잡한 배경의 무늬·구조를
복원한 것은 아니며 색 편차(p90)를 공개한다.

## GUI와 실행

기존 마스크 승인 → 원본 DWPose 승인 → **4단계 초기 이미지 검토** →
승인한 초기 이미지로 신체 복원 실행.

검토 화면은 원본, 원본 자세, 얼굴·손 표본 위치, 체형 후보,
피부/기본복/배경 영역, 실제 초기 이미지를 표시한다.
취소하면 GPU 복원은 시작하지 않는다. 잘못 선택된 피부색을 자동 확정하지 않는다.
현재는 표본/체형을 직접 편집하는 브러시 UI는 없다.

기존 회색 Human-Agnostic 검토 화면은 마스크 검증을 위해 유지하되,
신체 복원 Worker에는 새 초기 이미지를 전달한다.
프롬프트의 'neutral base layer'를 제거하고 불투명 기본복과 입력색 보존을 명시했다.
참조 의상 IP-Adapter와 외부 자세는 연결하지 않는다.

## 기록과 한계

GPU 실행 전에 기존 debug_benchmark 실행 디렉터리에 다음 PNG를 보존한다.

- body_initial, body_proxy, body_skin_region, body_basewear_region
- body_background_region, body_skin_samples, body_sample_overlay

metadata.json의 body_initialization에 원본 RGB 해시, 표본 수, 색상,
어깨 폭/몸통 길이, 영역별 픽셀 수, 배경 편차와 진단 파일 해시를 기록한다.
실행 실패에도 이 진단 자료는 남는다. 승인된 Body Base 영구 캐시는 아직 아니다.

자동 테스트는 분할 합집합/교집합, 원본·보호 픽셀 보존, 색 추출/손 비혼합,
잘못된 입력 거절, Worker 복사와 전달, 취소 시 미실행, 실패 시 산출물 보존을 확인한다.
실제 애니메이션 이미지의 체형 정확도, 피부색 정확도, 복원 품질이나 GPU 속도를
이 테스트만으로 보장하지 않는다. Stage 6 최종 품질 차단과 Stage 7 캐시는 별도 범위다.

2026-09-05 Windows 런타임 검증: 초기화 신규 14개를 포함한 관련 16개 테스트
모듈에서 138 passed (18.97초). GPU subprocess는 테스트에서 대체했으며 실제
생성은 실행하지 않았다. Linux 공유 작업 경로에서 코드를 수정했고 git diff --check를 통과했다.

## 구현 근거

- [OpenCV Drawing Functions](https://docs.opencv.org/4.13.0/d6/d6e/group__imgproc__draw.html):
  line/circle/fillPoly로 좌표 기반 영역을 래스터화한다.
- [NumPy median](https://numpy.org/doc/stable/reference/generated/numpy.median.html):
  선택된 색상 표본의 채널별 중앙값을 계산한다.

위 문서는 연산의 동작 근거이며, 관절 폭 계수나 볼 표본 위치의 정확도를 증명하지 않는다.
