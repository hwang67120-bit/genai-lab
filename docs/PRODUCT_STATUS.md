# 제품 품질 현황판

> **기본 화면은 사용자 화면(D-151)**: 참조 이미지 + '이미지 생성' + 생성 과정 미리보기 + '저장', 나머지 자동. 아래 기능별 표는 그 안에서 자동으로 도는 단계들이다.
> 작업실(GUI) 기능별로 '지금 동작하는가 · 마지막 품질 측정 · 알려진 문제'를 한곳에 둔다. 시험이 끝날 때마다 갱신한다(D-148).
> 동작 확인 = `scripts/product_smoke.py`(작업실 코드 경로를 화면 없이 끝까지: 입력 확인 → 생성 → 결과 → 승인 → 저장)와 `scripts/check_runtime_env.py`(패키지·작업 환경·모델 파일). 점검의 '승인'은 경로 확인이지 품질 판정이 아니다.

마지막 갱신: 2026-10-22 (D-153)

## 갱신 규칙

1. 환경을 바꾸거나 복구하면 `check_runtime_env.py` → 실패 0이어야 GUI 사용.
2. 생성·분석 코드를 바꾸면 해당 기능 `product_smoke.py` 한 번(미리보기는 약 12분).
3. 품질 측정(사용자 판정)이 끝나면 '마지막 품질 측정' 칸 갱신.
