## 판정
- 기준 조건: K0 붕괴 >= 4 이어야 비교한다. K0 붕괴 < 4 면 "무릎 seed 4~6 붕괴는 청크 구조 영향"으로 기록하고 안정화 판정은 불가.
- ST(X) 안정화: X 붕괴 <= K0 붕괴 − 3, 그리고 X 자세 "예" >= K0 자세 "예" − 1.
- ID(X) 얼굴 부작용 없음: X 캐릭터 "예" >= K0 캐릭터 "예" − 2.
- 채택 후보: ST 와 ID 가 모두 성립하는 조건. 여럿이면 붕괴가 적은 쪽, 같으면 K0 에서 바뀐 게 적은 쪽(K1/K2 < K3).
- K1 은 ST 성립, ID 불성립이고 K3 가 둘 다 성립하면 "골격을 늘리면 얼굴 시작도 늦춰야 한다".
