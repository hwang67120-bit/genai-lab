# 요청 38 결과 — 작업 프로세스 재사용(세션) 확인: 세션 작업이 멈춰 기록 후 중단 (2026-10-24, D-182)

## 결론

- **중단했다.** ② 장면 첫 시도(세션 작업 1)가 시작 직후 멈췄다(06:20:36부터 34분 동안 CPU 0.19초, 진행 기록 0). 승인 조건("예상 밖 차이나 오류가 있으면 기록 후 중단")대로 세션 작업 프로세스만 끝내고 기록했다. 재시도·대조 실행 없음.
- **원인(CPU 재현으로 확정): 제가 넣은 세션 코드의 결함.** 부모 감시 스레드(`watch_parent`)가 표준 입력 파이프를 막힌 채 읽는 동안, 주 스레드가 numpy의 네이티브 모듈(`numpy._core`, cv2 → `free_generation` 가져오기 경로)을 불러오다 멈춘다. Windows에서 같은 파이프 핸들에 대한 동기 입출력은 줄을 서므로, 불러오는 중인 라이브러리가 표준 핸들을 조회하면 대기 중인 읽기 뒤에서 막힌 것으로 본다(교착). 생성·패키징·GPU와는 무관하다.
- **그림 비교:** ① 옷 바꾸기(새 작업 프로세스 — 세션 대상 아님)의 raw는 요청 37과 **SHA까지 같다**. ②의 두 그림은 **만들어지지 않았다 → 비교 불가**(그림이 다른 '불일치'가 아니다). 품질 판정 대상이 아니다.
  - 정정(10/24, D-183): 실행기가 원래 `report.json`에 '불일치'로 적었다(만들어지지 않은 그림을 다른 그림과 같은 칸에 넣은 실행기 결함). 원본 `request38/report.json`은 그대로 두고, 실행기는 '비교 불가'를 따로 적게 고쳤다.
- 이 결과로 재사용의 효과(시간·메모리)는 확인하지 못했다. 재사용은 **기본 꺼짐 그대로**다.
