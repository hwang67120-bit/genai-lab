# 끊긴 꼬리 조각 보존 CPU 진단 — 실행 전 고정
날짜: 2026-10-07. 운영 미반영. 모델 추론·생성·설치·다운로드 없음.
## 질문
S06의 보이는 작은 꼬리 조각이 기존 최대 조각 중심선에서 빠지는가?
모든 유지 조각의 뼈대 끝점을 수집하면 정답 말단 상자 안 후보가 살아나는가?
이는 후보 포함 검사이며 말단 자동 선택 성공률이 아니다.
## 입력과 비교
기존 Claude CPU 재현 original/S03,S04,S05,S06,S07,S17의 mask.png, comparison.json과 원본 SHA를 대조한다.
T1b regions_t1b.json의 상자·말단 정답은 읽기만 한다. T1b 원시 마스크는 저장되지 않았으므로 이전 재현 마스크를 쓰며, T1b mask_px와 일치 여부도 별도 기록한다. 픽셀 수 일치만으로 마스크 바이트 동일을 주장하지 않는다.
6장은 이미 본 진단 자료다. 새 일반화 평가가 아니다.
## 고정 알고리즘
- 기존 마스크를 변경하지 않는다. 유지된 연결 성분을 전부 개별 처리한다(추가 면적 삭제 없음).
- 기존 비교: keep_parts의 최대 조각 + centerline_v2의 fine 양 끝.
- 후보: 각 성분의 Zhang-Suen thinning 뼈대에서 8이웃 수가 1인 모든 점. 닫힌 고리/점/분기는 기록. 끝점을 임의로 만들어 넣지 않는다.
- 원본 픽셀 좌표 유지. truth box는 후보 계산 함수에 전달하지 않고 사후 포함 여부만 평가한다.
- 조각 연결은 기하 후보만: 서로 다른 성분의 끝점 거리 <= 두 성분 최대 중앙 굵기의 4배.
  끝점 안쪽 BFS 경로 max(6px, 굵기의 2배)로 구한 바깥 방향과 연결선 각도가 양 끝 모두 <=45도.
- 여러 후보는 모두 남긴다. 자동으로 하나를 고르거나 연결하지 않는다.
- 몸/다리 의미 분할이 없으므로 모든 연결은 '가림 근거 미확인'. 배경색만으로 다리라고 판단하지 않는다.
- 점선은 비교 그림에만 표시. 색·무늬·참조·Qwen 입력/프롬프트에 사용하지 않는다.
- 실제 말단 가림, 다중 꼬리, 관계없는 끈의 의미 구분은 미검증이다.
## 검증과 종료
6장 입력 SHA·크기·상자를 확인. 합성 마스크 테스트로 두 조각, 한 조각, 분기, 고리, 잘못 향한 연결, 입력 불변을 점검.
보이는 말단 5장에 대해 기존/수정 후보 포함 여부를 보고하고 S07은 해당 없음으로 분리.
누락이 남으면 결과 그대로 보고하고 문턱/상자 조정 없이 종료한다.
가려진 형태 복원·생성 품질 향상은 판정하지 않는다. 전체 처리 시간·프로세스 최대 RAM 기록.
사용자 색 견본 24곳 판정은 대신하지 않는다. 운영 변경·커밋·푸시 없음.
