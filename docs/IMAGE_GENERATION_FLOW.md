## 프로젝트의 완료 범위

이 프로젝트는 캐릭터·의상·그림체를 갖춘 기준 이미지를 만들고, 필요한 자세·시점·원근 편집을 거쳐 최종 이미지 1장을 제공하는 것을 목표로 한다. 최종 산출물이 1장이라는 뜻이며, 내부 모델 호출이 반드시 1회라는 뜻은 아니다.

외부 LLM을 통한 소품·장신구·배경·조명 등의 추가 요청은 이 기본 흐름에서 분리한다. 기존 캐릭터나 의상에 이미 있는 장신구를 제거한다는 의미가 아니라, 완성 후 새 요소를 추가하는 요청의 책임을 구분한 것이다.

## 확정한 역할 순서

```text
캐릭터·의상 입력
    ↓
그림체·세부 표현을 적용한 이미지 생성
    ↓
사용자 확인 — 편집의 기준 이미지 확정
    ↓
자세·시점·원근 편집
    ↓
캐릭터·의상·그림체 보존 + 목표 자세 확인
    ↓
최종 이미지 1장
```

그림체·세부 표현은 자세 편집 이전에 완성한다. 자세 편집 이후 다시 그림체를 입히는 생성을 기본 단계로 넣지 않는다. 위 순서는 역할의 순서이며, 단계별 호출 횟수나 사용할 모델을 모두 확정한 것은 아니다.

## 이 순서로 정리한 이유

원래 의도는 그림체와 세부 표현을 먼저 갖추는 것이었다. 자세 적용 과정에서 이미지가 달라지는 문제를 확인하면서 자세 검증이 먼저 진행됐지만, 그것을 제품의 최종 처리 순서로 고정하지 않는다.

사용자가 확인한 이미지를 편집 기준으로 두면, 자세 편집이 보존해야 할 얼굴·의상·그림체를 직접 비교할 수 있다. 반대로 자세 편집 후 추가 생성으로 그림체를 다시 바꾸면, 그 생성에서 이미 맞춘 요소가 다시 달라지는지도 검증해야 한다.

이 순서를 선택한 목적은 보존 기준을 명확히 하는 것이다. 실제로 더 안전하거나 품질이 높은지는 아직 비교 검증되지 않았다.

## 자세 편집이 맡는 일과 보존 기준

| 구분 | 요구 사항 |
|---|---|
| 바꿀 것 | 요청한 자세, 필요한 시점과 원근, 이에 따른 자연스러운 가림·옷 주름 |
| 보존할 것 | 캐릭터 정체성, 의상 디자인·색·무늬·구성, 기준 이미지의 그림체와 세부 표현 |
| 확인할 것 | 목표 자세와 시점, 신체 구조, 의상 변형·소실, 정체성 변화, 원치 않은 요소 추가 |
| 최종 채택 | 사용자가 기준 이미지와 편집 결과를 비교해 확인 |

자세가 달라지면 보이는 면과 주름도 달라지므로 보존은 전체 픽셀 일치를 뜻하지 않는다. 같은 캐릭터·같은 옷·같은 그림체로 읽히는지를 확인한다. 가려져 보이지 않는 디자인은 확인 불가와 실제 소실을 구분한다.

Qwen 후보 시험의 질문은 **완성된 이미지의 캐릭터·의상·그림체를 유지하면서 자세를 바꿀 수 있는가**이다. Qwen이 이미 이를 충족한다고 가정하지 않는다.

## 외부 LLM 연동의 경계

기본 흐름이 끝난 뒤 다른 프로젝트에서 추가 요청이 있으면 다음 경로로 확장할 수 있다.

```text
이 프로젝트의 최종 이미지 + 사용자 추가 요청
    → 외부 LLM이 보존·변경·추가 조건을 정리
    → 이미지 편집 모델이 추가 결과 생성
    → 외부 프로젝트에서 결과 확인
```

소품·장신구·배경·조명·추가 그림 표현 등의 요청 정리는 외부 LLM의 역할이고, 실제 픽셀 생성은 이미지 모델의 역할이다. 이 연결 기능은 현재 흐름에 구현됐다고 간주하지 않는다.

## 그림체 학습의 위치와 미확정 사항

그림체 학습을 도입한다면 기준 이미지를 만드는 앞단에 적용하는 방향으로 검토한다. 구체적인 모델·데이터·LoRA·미세조정 또는 강화학습 방식은 아직 확정하지 않았다. 학습을 자동으로 시작하거나 사용자의 결과 선택만으로 모델이 갱신되는 구조도 이번 결정에 포함하지 않는다.

미측정 사항: Qwen의 자세·시점·원근 추종, 정체성·의상·그림체 보존, 실제 실행 환경의 메모리·속도. 그림체 학습의 품질 효과 역시 미측정이다.
