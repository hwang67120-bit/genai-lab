## 정답 라벨 (규칙 결과를 본 뒤, 이미지 단위)
- 라벨 대상: (1) PA 거부 이미지 전부, (2) PA 통과 이미지 중 무작위 60장 (Python random.Random(20260929).sample, 파일 경로 정렬 후)
- 라벨: "두 번째 인물" (사람 또는 사람으로 읽히는 실루엣이 캐릭터 외에 있음) / "그림자만" (바닥에 붙은 그림자) / "없음" / "판단 어려움"
- 라벨은 이미지를 보고 적되, 태그 점수는 라벨 시트에 표시하지 않는다.

## 판정 (해석표, 보고에는 행 번호만)
- 오탐률 = (PA 거부 중 "없음"+"그림자만") / (PA 거부 중 판단 어려움 제외)
- 놓침 추정 = (표본 60 중 "두 번째 인물") / (표본 중 판단 어려움 제외)
- PG1: 오탐률 <= 20% 그리고 표본 놓침 0 → 게이트 후보
- PG2: 오탐률 > 20%, 표본 놓침 0 → 걸러내지만 오탐이 많음
- PG3: 표본 놓침 >= 1 → 놓침 있음
- PG4: PA 거부 0건이라 오탐 평가 불가
