## 가설
pose-norm-20260928 결과는 자세 사진 속 사람의 몸 비율을 따라갔다. 예: POCKET 어깨폭(몸통 대비) 캐릭터 0.42, 사진 0.59, 결과 0.50 /
허벅지 0.93, 0.76, 0.73. 관절 방향은 자세 사진에서, 뼈 길이는 캐릭터에서 가져오면 결과 비율이 캐릭터에 가까워진다.

## 리타게팅 (제어 이미지만 바뀜)
1. pose-norm 의 정규화 이미지 norm_{자세}.png 에 DWPose 를 다시 돌려 전체 점(몸 18, 손, 얼굴)을 얻는다 (pose-norm 과 같은 검출).
2. 캐릭터 몸 18점: pose-range controls.json inputs (캐릭터 입력 이미지 검출).
3. 축척 s = 목표 몸통 / 캐릭터 몸통 (몸통 = 목 ~ 두 엉덩이 중점).
4. 목(1)을 고정하고 다음 순서로 다시 잇는다: (1,2)(2,3)(3,4)(1,5)(5,6)(6,7)(1,8)(8,9)(9,10)(1,11)(11,12)(12,13)(1,0)(0,14)(14,16)(0,15)(15,17).
   방향 = 목표 골격의 부모→자식 단위 벡터. 길이 = (1−α)·목표 길이 + α·(캐릭터 길이 × s).
   목표 두 점 중 하나라도 신뢰도 < 0.30 이면 목표의 상대 위치를 그대로 쓰고, 캐릭터 뼈가 신뢰도 미달이면 목표 길이를 쓴다.
   α = 1.0 (KNEEL, POCKET, GUN), 0.5 (HIGH, LOW: 원근이 강한 자세).
5. 얼굴 68점: 새 코 위치 기준으로 옮기고, (새 목-코 길이 / 목표 목-코 길이) 배율로 크기를 바꾼다.
   손 21점씩: 각 손목의 이동만큼 평행 이동 (왼손 = 몸 7번, 오른손 = 몸 4번).
6. 크기 재맞춤: 리타게팅 뒤 몸 18점 경계 상자의 중심과 채움 비율 max(높이/1232, 폭/736)을 리타게팅 전과 같게 균일 축척·이동한다.
7. easy_dwpose.draw.draw_openpose 로 그리고 (pose_reference_runner 와 같은 인자), prepare_pose_control_input(736×1232), 카드대로 채널 반전.
8. 골격 검사 K1~K6 통과해야 한다. 거부되면 그 조합은 생성하지 않는다.
캐릭터마다 골격이 달라지므로 제어 이미지는 5 자세 × 2 캐릭터 = 10개.

## 측정
- 비율 오차 E (결과마다): 결과 DWPose 몸 18점에서 몸통 대비 [어깨폭, 허벅지(좌우 중 긴 쪽), 정강이(좌우 중 긴 쪽)] 비율을 구하고,
  캐릭터 입력의 같은 비율과의 절대 차이 평균. 필요한 관절 신뢰도 < 0.30 이면 해당 항목 제외, 셋 다 없으면 미측정.
  pose-norm 30장에도 같은 방법으로 계산해 비교한다.
- 육안 라벨 V1~V4 (pose-norm 과 같은 항목, 결과 태깅 전 잠금). 노출 v4 와 의상 D 검사 기록.
