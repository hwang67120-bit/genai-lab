# 체형 비율 프리셋 v3

## 목적

OpenPose로 자세를 바꾸기 전에 정면 전신 기준 이미지를 안정적으로 만들기
위한 사람 형태의 체형 기준 자산이다. 승인한 프리셋을 Animagine Base 첫 생성에만 연결한다.

## 구성

| 계열 | 프리셋 |
| --- | --- |
| SD | 3등신 중립 |
| 아동 | 5등신 중립 |
| 표준 성인 | 7.5등신 어깨 중심, 골반 중심 |
| 패션 성인 | 8등신 어깨 중심, 골반 중심 |

SD는 그림의 데포르메 비율이며 연령을 뜻하지 않는다. 아동 5등신과 별도
계열로 관리한다. 아동과 SD에는 성별에 따른 가슴·골반 차이를 강제하지 않는다.

성인 프리셋도 남성·여성으로 고정하지 않는다. 어깨 중심과 골반 중심은
관찰 가능한 형태 이름이며 캐릭터 성별은 별도 요청에서 결정한다. 남성
캐릭터의 여성 의상처럼 성별과 의상 조합이 바뀌어도 체형 프리셋이 성별
게이트로 작동하지 않게 하기 위한 분리다.

## 자산 출처

원본 시트는 사용자가 제시한 두 인체 구조 이미지를 구조 참고로만 사용해
프로젝트용으로 새로 생성했다. 참조 이미지의 캐릭터, 의상, 동물귀, 헤어,
문구와 디자인은 복사하지 않았다. 원본 해시와 각 패널의 크롭 좌표는
manifest.json에 기록한다.

이전 코드 생성 기하 실루엣 v1/v2는 인체 기준으로 부적합해 폐기했다.

## 사용 계약

- 정면 중립 사람 형태와 등신 눈금만 표현한다.
- 얼굴 정체성, 헤어, 의상, 동물귀, 꼬리와 그림체 조건을 포함하지 않는다.
- 캐릭터 성별과 체형 프리셋은 독립 조건이다.
- GUI에서 프리셋을 명시적으로 선택한 전신 요청에만 적용한다.
- Animagine Base 첫 생성은 별도 SDXL Canny ControlNet으로 체형 기준선을 받는다.
- 기본 가중치는 0.42이며 전체 스텝의 0.00~0.72 구간에만 적용한다.
- IP-Adapter 입력에는 체형 시트를 넣지 않는다.
- FLUX에는 승인된 Base와 의상 보드만 전달한다.
- OpenPose는 기준 이미지가 승인된 이후 자세 변경 단계에서만 사용한다.
- 전신이 아닌 요청, 프리셋 미선택 요청, 자세 ControlNet 요청에서는 체형 ControlNet을 사용하지 않는다.
- manifest의 approved_asset은 자산 승인을 뜻하며 런타임 연결 상태는 configs/animagine.yaml에서 관리한다.
